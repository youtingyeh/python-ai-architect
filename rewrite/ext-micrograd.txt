@section 開場：拆開黑盒子，自己做一個「迷你 PyTorch」
在第 4 課，我們學到 PyTorch 會自動幫我們算梯度：寫完計算式，呼叫一句 `loss.backward()`，所有參數的梯度就出現了。很神奇，但它像一個黑盒子：你知道它有用，卻不知道裡面發生了什麼事。

這一課要做的，就是**親手把這個黑盒子打開**。

我們跟著 Andrej Karpathy 的課程《Neural Networks: Zero to Hero》（神經網路：從零到英雄）來學。Karpathy 是深度學習界很有名的研究者和教育者，曾參與 OpenAI 的創立、也曾擔任特斯拉自動駕駛 AI 部門的負責人。他寫了一個叫做 **micrograd** 的小程式，只用大約一百行 Python，就實作出了自動微分引擎和一個小型神經網路。

為什麼要學一個「玩具版」？因為 micrograd 和 PyTorch 的核心原理**完全一樣**。差別只在於：PyTorch 一次處理一大塊張量（幾百萬個數字一起算），而 micrograd 一次只處理**一個數字**（純量）。數字少了，每一步就看得清清楚楚。

Karpathy 有一句名言：如果你能從零寫出反向傳播，你就真正理解了神經網路。學完這一課，你會發現所謂的「深度學習」，拆到最底層，只是**加法、乘法，加上一條鏈式法則**。

這一課我們會：
1. 認識「會記住自己從哪裡來」的數字；
2. 搞懂加法和乘法如何傳遞梯度；
3. 看激活函式如何像閘門一樣控制梯度；
4. 理解一個常見致命錯誤：`=` 和 `+=` 的差別；
5. 學會反向傳播為什麼要「排好順序」；
6. 用這些零件組出一個真正的神經網路。

@section 一個「會記住自己從哪裡來」的數字
平常在 Python 裡寫 `c = a * b`，算完之後 `c` 就只是一個數字，例如 −6.0。它不記得自己是怎麼來的。

micrograd 的核心，是把每個數字包裝成一個叫 **Value** 的物件。Value 除了記住數值，還會記住**自己的身世**。當我們寫：

```
a = Value(2.0)
b = Value(-3.0)
c = a * b
```

系統不只算出 −6.0，還會記下「c 是由 a 和 b **相乘**產生的」。所有這些「誰由誰產生」的關係連起來，就是第 4 課說過的**計算圖**——一張有方向、不會繞回原點的關係圖（DAG，有向無環圖）。

每個 Value 內部有四個欄位，像一張身分證：

**① data（數值）**：前向傳播算出來的數字，例如 c 的 data 是 −6.0。

**② grad（梯度）**：最終損失 L 對這個數字的敏感度，寫成 $\frac{\partial L}{\partial \text{self}}$。一開始設為 0.0，代表「還沒收到任何梯度」。反向傳播時會被填上。

**③ _prev（父母）**：產生這個數字的那幾個數字。例如 c 的 _prev 是 {a, b}。這就是計算圖的「連線」。

**④ _backward（傳遞規則）**：一個小函式，說明「當我收到上游傳來的梯度時，要怎麼分給我的父母」。乘法有乘法的規則，加法有加法的規則。

（程式名稱前面的底線 `_` 是 Python 的慣例，表示「這是內部使用的，一般使用者不用碰」。）

只要理解這四個欄位怎麼互相合作，就等於看穿了所有深度學習框架最底層的運作方式。

@section 每個運算只需要知道「自己那一小段」
反向傳播看起來很複雜，但它有一個非常聰明的設計：**每個運算節點不需要知道整個網路長什麼樣子，只需要知道自己那一小段的規則。**

這來自第 4 課的鏈式法則。假設某個運算是 $\text{out} = f(a, b)$，而我們已經知道「最終損失對 out 的敏感度」（也就是 `out.grad`，從上游傳來的）。那麼要算損失對 a 的敏感度，只需要：

$$\frac{\partial L}{\partial a} = \frac{\partial L}{\partial \text{out}} \cdot \frac{\partial \text{out}}{\partial a}$$

白話說：**上游傳來的梯度 × 我自己這一步的局部導數**。

「局部導數」（Local Derivative）就是「只看這一步，輸入變一點，輸出變多少」。它跟網路多深、損失函數長怎樣完全無關。就像接力賽，每個跑者只要負責跑好自己這一棒、把棒子正確交給下一位，不需要知道整場比賽的路線。

最基礎的兩種運算，加法和乘法，有完全不同的傳遞性格：

**加法：梯度的「影印機」。**

$\text{out} = a + b$。a 增加 1，out 就增加 1；b 也一樣。所以兩個局部導數都是 1：

$$\frac{\partial (a+b)}{\partial a} = 1, \quad \frac{\partial (a+b)}{\partial b} = 1$$

結果是：加法節點會把上游傳來的梯度**原封不動地複製一份**，分別給 a 和 b。例如 out.grad = −2.0，那 a 和 b 都收到 −2.0。

直覺：如果一個總和對結果有影響，那每一個加進去的項，影響力都一樣大。

**乘法：梯度的「交換放大器」。**

$\text{out} = a \times b$。a 增加 1，out 會增加 b 那麼多；b 增加 1，out 會增加 a 那麼多：

$$\frac{\partial (ab)}{\partial a} = b, \quad \frac{\partial (ab)}{\partial b} = a$$

所以乘法節點傳梯度時，**會交換**：給 a 的梯度要乘上 **b 的值**，給 b 的梯度要乘上 **a 的值**。程式寫成 `a.grad += b.data * out.grad`。

**實際算一次。**$a = 2.0$、$b = -3.0$、out.grad = −2.0：
- a 收到：$(-3.0) \times (-2.0) = +6.0$
- b 收到：$(2.0) \times (-2.0) = -4.0$

a 的梯度 +6.0 是什麼意思？代表「把 a 調大一點，最終損失 L 會**上升**」。所以如果我們想讓損失下降，應該把 a 調**小**。

**再練一題。**$a = -4.0$、$b = 2.5$、上游傳來 c.grad = −2.0，$c = a \times b$：
- a 收到：$2.5 \times (-2.0) = -5.0$
- b 收到：$(-4.0) \times (-2.0) = +8.0$

a 的梯度是負的（−5.0），代表把 a 調**大**一點（往正方向），損失會下降。

@section 激活函式：梯度的閘門
第 8 課學過，只有加法和乘法的網路，疊再多層也只是一條直線。所以要在每個神經元的「加權總和」之後，加上非線性的**激活函式**。micrograd 裡最經典的兩個是 **tanh** 和 **ReLU**。

在反向傳播時，激活函式扮演「**閘門**」的角色：它決定從上游流下來的梯度，能有多少通過、流回前面的權重。

**tanh（雙曲正切）：一條 S 形曲線。**

$t = \tanh(x)$ 會把任何數字壓縮到 −1 到 1 之間。輸入很大的正數，輸出接近 1；很大的負數，接近 −1；0 附近則近似一條斜線。它的公式是 $\frac{e^{2x} - 1}{e^{2x} + 1}$，但你不用記，只要知道它是一條 S 形曲線。

它的導數有一個非常漂亮的形式，可以直接用輸出 t 來算：

$$\frac{dt}{dx} = 1 - t^2$$

用這個公式看閘門開多大：
- 輸入 $x = 0$：$t = 0$，局部導數 $1 - 0 = 1.0$。**閘門全開**，梯度 100% 通過。
- 輸入 $x = 4$：$t \approx 0.9993$，局部導數 $1 - 0.9993^2 \approx 0.0013$。**閘門幾乎關死**，梯度只剩千分之一點三。

當輸入的數字太大或太小，tanh 會進入曲線的平坦區，叫做「**飽和區**」（Saturation）。在飽和區，梯度幾乎無法通過。如果網路很深，每一層都打折一點，傳到最前面幾層時梯度可能就趨近於 0，前面的權重幾乎學不動——這就是第 7 課提過的「**梯度消失**」的主要元兇之一。

**ReLU：開或關的開關。**

$\text{ReLU}(x) = \max(0, x)$。它的導數更簡單：
- $x > 0$ 時，導數永遠是 1：**閘門全開**，而且不管 x 多大都不會飽和。
- $x \le 0$ 時，導數永遠是 0：**閘門全關**。

ReLU 解決了正數那一側的飽和問題，這是它在現代深度學習中這麼受歡迎的原因。但它也有自己的毛病：如果某個神經元因為權重更新不當，對**所有**輸入都算出負數，那它的輸出永遠是 0、梯度也永遠是 0，再也無法被更新，等於「死掉了」。這叫做「**Dead ReLU**」（神經元壞死）。這也是後來出現 GELU 等改良版本的原因之一。

@section 致命小錯：為什麼一定要寫 += 而不是 =
手刻 micrograd 時，最常犯、也最難察覺的錯誤，是在傳遞梯度時寫成：

```
self.grad = ...    # 錯
```

而不是：

```
self.grad += ...   # 對
```

在簡單的算式裡，例如 $L = (a \times b) + c$，每個數字只用到一次，用 `=` 看起來也能算對。但**只要同一個數字在算式裡被用了兩次以上**，`=` 就會算錯。

**為什麼？**第 4 課的「兩條支流」：如果一個數字 x 透過好幾條路徑影響最終結果，那麼總敏感度必須是**所有路徑的貢獻加總**：

$$\frac{\partial L}{\partial x} = \sum_{i=1}^{k} \frac{\partial L}{\partial u_i} \cdot \frac{\partial u_i}{\partial x}$$

（$u_1, u_2, \dots, u_k$ 是 x 影響結果的各條路徑。）

**最簡單的例子：$b = a + a$，其中 $a = 3$。**

正確答案顯然是 $\frac{\partial b}{\partial a} = 2$（a 出現兩次，a 增加 1，b 增加 2）。

但在程式裡，加法的「左邊」和「右邊」**指向同一個物件 a**。反向傳播時：
1. 處理左邊：`a.grad = 1.0 × b.grad`，a.grad 變成 1.0。
2. 處理右邊：`a.grad = 1.0 × b.grad`，**又把 a.grad 設成 1.0**，剛剛那份被覆蓋掉了！

最後 a.grad 是 1.0，而不是 2.0。換成 `+=`，第二次是「加上去」，就會得到正確的 2.0。

**再複雜一點：$y = x \times x + x$，其中 $x = 3$。**

正確梯度是 $2x + 1 = 7$。如果用 `=`，後執行的那條路徑會覆蓋前面的，最後可能只得到 1.0 或 3.0（看執行順序），完全錯誤。

這種「同一個數字被重複使用」的情況在神經網路裡非常常見：例如**殘差連接**（$y = f(x) + x$，讓輸入跳過一層直接加回來，現代深度網路的關鍵設計），或**權重共享**（同一組權重用在好幾個地方）。

這也解釋了第 4 課的一個謎題：**為什麼 PyTorch 的梯度預設是累加的，而且每輪訓練前一定要 `zero_grad()` 清零？**因為「累加」才是數學上正確的做法；既然會累加，每一輪開始前就必須先清空，否則上一輪的梯度會混進來。

@section 反向傳播要排好順序：拓撲排序
當計算圖變複雜、有好幾條路徑匯合時，不能隨便挑一個節點就開始傳梯度。

**看一個例子：**
```
d = a * b
e = a + d
L = e * d
```

注意 d 被用了兩次：一次直接給 L，一次先變成 e 再給 L。所以 d 要收到**兩份**梯度（一份直接從 L 來，一份從 e 繞回來），加起來才完整。

如果我們太早處理 d——在 e 還沒把它那份梯度傳給 d 之前，就先執行 d 的傳遞規則，把梯度往下分給 a 和 b——那 a 和 b 收到的就是**不完整**的梯度，漏掉了「經過 e 繞一圈回來」的那一部分。

所以反向傳播有一條鐵律：**任何節點在把梯度往下傳之前，所有用到它的下游節點，都必須已經先把梯度傳給它了。**

這就像工廠的組裝流程：一個零件要等所有下游工作站的回饋都收齊了，才能做最後的調整。

在圖論（研究點和連線的數學）裡，滿足「所有依賴關係都排在前面」的順序，叫做「**拓撲排序**」（Topological Sort）。最常見的生活例子是排課：「微積分一」一定要排在「微積分二」前面，「資料結構」要排在「演算法」前面。

micrograd 建立拓撲順序的方法：
1. 從最終的損失 L 出發，用「**深度優先搜尋**」（DFS，一路往深處走到底、再退回來換條路）去拜訪每個節點的父母。
2. 用一個「拜訪過」清單避免重複拜訪。
3. **只有當一個節點的所有祖先都已經排進清單後，才把它自己加進去。**

這樣排出來的清單，最前面是最原始的輸入（叫做**葉節點**，Leaf Node，就像樹的葉子，沒有更上游的來源），最後一個是損失 L。

接著：
1. 把 L.grad 設為 1.0（L 對自己的敏感度是 1）。
2. **把清單倒過來**，從 L 開始，逐一執行每個節點的傳遞規則。

這樣保證每個節點都在「收齊所有下游梯度」之後才往下傳。整個過程只需要把每個節點和每條連線各走一次，計算量和圖的大小成正比，非常有效率。

**為什麼不能用「一層一層往外擴散」（廣度優先搜尋 BFS）邊走邊傳？**因為擴散的順序不保證「下游先處理完」。遇到 d 這種被好幾條路共用的節點，可能在它還沒收齊梯度時，就被提早處理了。

@section 從一個數字到一個神經網路
有了會自動求梯度的 Value，組一個神經網路就只是「把加法、乘法和 tanh 包裝成積木」而已。micrograd 用三層積木來搭：

**積木一：神經元（Neuron）。**
一個神經元有 `nin` 個輸入（nin 是 number of inputs）。它內部有：
- `nin` 個權重 $w$，一開始隨機設在 −1 到 1 之間；
- 一個偏置 $b$，一開始設為 0。

收到輸入 $x$ 時，它做兩件事：先算加權總和 $\sum w_i x_i + b$（第 5 課的直線、第 3 課的加權總分），再通過 tanh 激活函式。

這就是「人工神經元」名字的由來：它粗略模仿生物神經元——收集來自很多其他神經元的訊號，加權總和後，超過某個程度就「激發」。

**積木二：層（Layer）。**
把好幾個神經元並排，每個都接收同樣的輸入、各自算出一個輸出。例如一層有 4 個神經元，就輸出 4 個數字。

**積木三：多層感知機（MLP）。**
把好幾層頭尾接起來。例如 `MLP(3, [4, 4, 1])` 的意思是：
- 輸入 3 個數字；
- 第一個隱藏層 4 個神經元；
- 第二個隱藏層 4 個神經元；
- 輸出層 1 個神經元。

**它有幾個參數？**每個神經元的參數數 = 輸入數 + 1（偏置）：
- 第一層：4 個神經元 × (3 + 1) = 16
- 第二層：4 個神經元 × (4 + 1) = 20
- 輸出層：1 個神經元 × (4 + 1) = 5
- 合計：**41 個**參數，每一個都是一個 Value。

每個積木都提供一個 `parameters()` 方法，把裡面所有的權重和偏置收集成一張清單，方便統一更新。

**訓練迴圈和第 8 課一模一樣：**
1. **前向**：把輸入送進 MLP，得到預測 `ypred`。
2. **算損失**：用均方誤差，把每筆「預測減答案」的平方加起來。
3. **清零＋反向**：先把所有參數的 grad 歸零，再呼叫 `loss.backward()`，梯度自動貫穿整張由幾百個 Value 組成的計算圖。
4. **更新**：每個參數往梯度的反方向走一小步：`p.data += -lr * p.grad`（lr 是學習率）。

重複幾十次，你就會看到損失一路下降，模型學會了把輸入對應到正確的輸出。

這套不依賴任何外部工具、只有一百多行的程式，和訓練 GPT-4 這種巨型模型的核心數學迴圈，**本質上是同一件事**。差別只在規模：GPT 的參數是幾千億，而且是用張量一次處理成千上萬個數字，在幾千張顯示卡上平行計算。

@section 跟著算一次：手動走完一張小計算圖
我們手動算一個完整的小例子，親自當一次 micrograd。

**算式**：$a = 2$、$b = -3$、$c = 10$。
- $e = a \times b = -6$
- $d = e + c = 4$
- $L = d \times f$，其中 $f = -2$，所以 $L = -8$

**反向傳播（從 L 往回）**：

1. **L 對自己**：L.grad = 1.0。

2. **經過 $L = d \times f$（乘法，交換放大）**：
   - d.grad = f.data × L.grad = $-2 \times 1 = -2$
   - f.grad = d.data × L.grad = $4 \times 1 = 4$

3. **經過 $d = e + c$（加法，原樣複製）**：
   - e.grad = d.grad = −2
   - c.grad = d.grad = −2

4. **經過 $e = a \times b$（乘法，交換放大）**：
   - a.grad = b.data × e.grad = $(-3) \times (-2) = 6$
   - b.grad = a.data × e.grad = $2 \times (-2) = -4$

**結果**：a.grad = 6、b.grad = −4、c.grad = −2、f.grad = 4。

**驗證一下 a.grad = 6 對不對**：把 a 從 2 稍微調成 2.001，看 L 變多少。
- $e = 2.001 \times (-3) = -6.003$
- $d = -6.003 + 10 = 3.997$
- $L = 3.997 \times (-2) = -7.994$
- L 從 −8 變成 −7.994，增加了 0.006；除以 a 的變化 0.001，得到 **6**。完全吻合！

（這就是第 4 課說的「有限差分」，拿來**檢查**自動微分算得對不對，正是它最好的用途。）

**如果想讓 L 變大**（例如這是一個要最大化的分數），就應該把 a 調大（梯度 +6）、b 調小（梯度 −4）、c 調小（梯度 −2）、f 調大（梯度 +4）。你只用加法和乘法的兩條規則，就完成了一次完整的反向傳播。

@section 本課重點整理
- **micrograd** 用一百行程式實作自動微分，和 PyTorch 原理完全相同，只是一次處理一個數字。
- **Value 有四個欄位**：數值（data）、梯度（grad）、父母（_prev）、傳遞規則（_backward）。
- **每個節點只管自己那一段**：上游梯度 × 局部導數。
- **加法是影印機**：梯度原樣複製給每個輸入。**乘法是交換放大器**：給 a 的梯度乘上 b 的值，給 b 的乘上 a 的值。
- **激活函式是閘門**：tanh 的導數是 $1 - t^2$，在飽和區幾乎關死，造成梯度消失；ReLU 正數全開、負數全關，可能造成神經元壞死。
- **一定要用 +=**：同一個數字被用多次時，梯度必須累加。這也是 PyTorch 要 `zero_grad()` 的原因。
- **反向傳播要照拓撲排序的反順序**：確保每個節點收齊所有下游梯度後才往下傳。
- **神經元 → 層 → MLP**：`MLP(3, [4, 4, 1])` 有 41 個參數，訓練迴圈和 PyTorch 一模一樣。

下一課，我們用同樣的「從零開始」精神，打造第一個**語言模型**：一個只靠統計「哪個字後面常接哪個字」，就能自己編出名字的小程式。

@term micrograd
Andrej Karpathy 寫的約一百行教學用自動微分引擎，一次處理一個數字，原理和 PyTorch 相同。
@term Value
micrograd 中包裝數字的物件，會記住數值、梯度、由誰產生，以及如何把梯度往回傳。
@term 局部導數
只看單一運算這一步時，輸入變一點、輸出變多少（Local Derivative）。反向傳播時乘上上游梯度。
@term 飽和區
激活函式曲線變得很平的區域（Saturation），導數接近 0，梯度幾乎無法通過。
@term tanh
雙曲正切函式，S 形曲線，把任何數字壓到 −1 到 1 之間。導數是 1 − t²。
@term Dead ReLU
ReLU 神經元對所有輸入都輸出負值，梯度永遠為 0、再也無法更新的現象（神經元壞死）。
@term 殘差連接
讓輸入跳過一層直接加回輸出的設計（y = f(x) + x），讓深層網路更好訓練。
@term 拓撲排序
把有依賴關係的項目排成「被依賴的永遠在前面」的順序（Topological Sort），像排先修課程。
@term 深度優先搜尋
走訪圖時一路往深處走到底、再退回來換下一條路的方法（DFS）。
@term 葉節點
計算圖中最原始、沒有更上游來源的輸入節點（Leaf Node），例如權重和原始輸入。
@term 神經元
神經網路的基本單位：把輸入加權總和、加上偏置，再通過激活函式（Neuron）。
