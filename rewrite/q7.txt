@section 開場：量子世界的「頻率分析」
如果你學過訊號處理或音樂，可能聽過**傅立葉轉換**：它能把一段聲音拆解成不同頻率的組合，告訴你裡面有哪些音高。手機的音樂辨識、MP3 壓縮、影像處理，背後都有傅立葉轉換。

量子電腦也有自己的版本，叫做**量子傅立葉轉換**（Quantum Fourier Transform，QFT）。它是許多最重要量子演算法的核心：
- **Shor 的因數分解演算法**（下一課）；
- **量子相位估計**（本課），它又是量子化學模擬、HHL 線性方程演算法等的基礎。

這一課會介紹：
- 古典離散傅立葉轉換的直覺；
- QFT 做了什麼、怎麼用量子閘實現；
- 量子相位估計：怎麼「讀出」一個藏在相位裡的數字；
- 為什麼 QFT 這麼快，但又不能直接拿來加速一般的傅立葉轉換。

@section 傅立葉轉換的直覺：找出週期
**找出週期**
想像一串數字：3, 1, 4, 3, 1, 4, 3, 1, 4, …。你一眼就能看出它每 3 個重複一次，週期是 3。傅立葉轉換做的事情，本質上就是**找出資料中的週期性（頻率）**。如果一個訊號的週期是 r，傅立葉轉換後，在「頻率 N/r 的倍數」那些位置會出現明顯的尖峰。

**時鐘的比喻**
想像有很多時鐘，每個時鐘的指針以不同的速度轉動。傅立葉轉換就像是：拿你的資料去和每一個速度的時鐘「比對步調」。速度和資料週期吻合的時鐘，比對分數就很高；不吻合的，各時間點的貢獻互相抵消，分數接近零。

這個「吻合就加強、不吻合就抵消」的機制，你應該已經很熟悉了：這就是**干涉**，也是所有量子演算法的核心。這正是為什麼傅立葉轉換和量子電腦是天作之合。

**單位圓上的點**
在數學上，「時鐘指針」用單位圓上的複數表示。第 87 課學過，e^(iφ) 是單位圓上角度為 φ 的點。轉一整圈是 2π。把圓周分成 N 等份，第 k 個點就是 e^(2πik/N)。傅立葉轉換就是把資料和這些「轉動中的指針」做比對。

@section 量子傅立葉轉換做了什麼
**定義**
對 n 個量子位元（N = 2ⁿ），QFT 把基底狀態 |x⟩ 變成：
QFT|x⟩ = (1/√N) Σₖ e^(2πi·xk/N) |k⟩

也就是說，輸入 x 被轉換成一個均勻疊加，但每一項 |k⟩ 都帶著一個相位，相位轉動的「速度」由 x 決定。

**和 H 閘的關係**
n = 1 時，N = 2，QFT 剛好就是 H 閘：|0⟩ → (|0⟩ + |1⟩)/√2、|1⟩ → (|0⟩ − |1⟩)/√2。第 91 課提過 H⊗ⁿ 是一種「0、1 世界的傅立葉轉換」；QFT 則是更一般的版本，相位可以是圓周上任意的 N 等份，而不只是 +1 和 −1。

**乘積形式：QFT 的關鍵洞見**
QFT 的輸出，雖然看起來是一個很複雜的疊加，其實可以拆成每個量子位元**各自獨立**的狀態的張量積！第 j 個量子位元的狀態是：
(|0⟩ + e^(2πi·0.x_j…x_n)|1⟩)/√2

其中 0.x_j…x_n 是一個二進位小數。不用記住這個公式，重點是：**每個輸出量子位元只是 |0⟩ 和 |1⟩ 的等量疊加，差別只在相對相位**。而相位由輸入的位元決定。

這個結構告訴我們怎麼用量子閘來實現 QFT。

@section 用量子閘實現 QFT
**需要的閘**
- **H 閘**：製造等量疊加；
- **受控相位旋轉閘** CR_k：如果控制位元是 1，就在目標位元的 |1⟩ 上加上相位 e^(2πi/2ᵏ)，也就是旋轉 360°/2ᵏ。

**電路結構**
1. 對第一個量子位元做 H；
2. 用第二個量子位元控制，對第一個做 CR₂（轉 90°）；
3. 用第三個控制，對第一個做 CR₃（轉 45°）；
4. …一直到第 n 個；
5. 接著對第二個量子位元重複類似的步驟（H，然後被後面的量子位元控制旋轉）；
6. …對每個量子位元都做一次；
7. 最後把量子位元的**順序反轉**（用 SWAP 閘）。

**閘數量**
第一個量子位元需要 1 個 H 和 n−1 個受控旋轉，第二個需要 n−2 個，……總共大約 **n²/2** 個閘。

古典的**快速傅立葉轉換**（FFT）處理 N = 2ⁿ 個數字，需要大約 N log N = n·2ⁿ 步。而 QFT 只需要約 n² 個閘。這是**指數級**的差距！

**近似 QFT**
當 k 很大時，CR_k 的旋轉角度非常小（360°/2ᵏ），對結果影響極小。實務上可以把太小的旋轉省略，只保留大約 log n 層，這叫做**近似 QFT**，閘數降到約 n log n，精確度幾乎不受影響。在有雜訊的硬體上，省略這些閘反而可能讓結果更好，因為每多一個閘就多一份雜訊。

@section 為什麼 QFT 不能直接加速 FFT？
看到「n² vs n·2ⁿ」，你可能會想：太好了，以後所有傅立葉轉換都用量子電腦做！可惜沒那麼簡單。這是理解量子演算法非常關鍵的一點。

**問題一：資料載入**
FFT 的輸入是 N 個數字。要用 QFT，必須先把這 N 個數字編碼成量子狀態的機率幅，這通常需要和 N 成正比的步驟（第 92 課提過的資料載入瓶頸）。

**問題二：無法讀出結果**
QFT 的輸出是一個有 N 個機率幅的量子狀態。但第 90 課說過，測量只能得到一個結果，而且是隨機的。要估計所有 N 個機率幅，需要非常多次的執行。你**無法**把 QFT 的完整結果讀出來。

**那 QFT 有什麼用？**
QFT 適合用在一種特殊情況：**輸入狀態是由量子演算法自己產生的**（不用載入），而**我們只需要知道一個全域性質**（例如週期），不需要完整的頻譜。測量 QFT 的輸出，會以高機率得到和週期相關的數字，這就夠了。

這正是 Shor 演算法和相位估計的情況。這個模式值得記住：**量子演算法的優勢，通常在於「輸入是量子產生的、輸出只要一個全域性質」**。

@section 量子相位估計：讀出藏在相位裡的數字
**問題**
有一個么正操作 U，和它的一個**特徵向量** |u⟩，滿足：
U|u⟩ = e^(2πiφ)|u⟩

也就是說，U 作用在 |u⟩ 上只會乘上一個相位。φ 是一個 0 到 1 之間的數字。我們想知道 φ 是多少。

**為什麼這個問題重要？**
- 在量子化學中，分子的**能量**就藏在這種相位裡（U 是分子的時間演化），相位估計可以計算分子的基態能量；
- 在 Shor 演算法中，要找的**週期**也藏在相位裡；
- 許多其他演算法（量子計數、HHL 線性方程演算法）都以它為核心。

**演算法步驟**
用兩組量子位元：t 個「計數位元」（決定精確度）和一組放 |u⟩ 的位元。
1. 對所有計數位元做 H，得到均勻疊加；
2. 用第 j 個計數位元，**控制**執行 U 共 2ʲ 次；
3. 透過**相位回踢**（第 91 課），每個計數位元都得到相位 e^(2πi·2ʲφ)；
4. 這時候，計數位元的狀態，剛好就是 QFT 的乘積形式！
5. 做**反向 QFT**，把相位轉換回數字；
6. 測量計數位元，得到 φ 的 t 位元二進位近似值。

**直覺**
步驟 2–4 等於在計數位元上「寫下」一個 QFT 的輸出，裡面藏著 φ 的資訊；步驟 5 用反向 QFT 把它「翻譯」回一般的數字。

**精確度與成本**
想要 t 位元的精確度，就要執行受控 U 大約 2ᵗ 次。所以精確度每增加一個位元，成本就加倍。另外，相位估計需要很深的電路，對雜訊非常敏感，通常被視為需要**容錯量子電腦**的演算法。

**NISQ 時代的替代方案**
因為相位估計太深，在今天有雜訊的硬體上，量子化學通常改用第 98 課的**變分量子特徵值求解器**（VQE）。VQE 電路淺得多，但需要大量量測與古典優化，也沒有相位估計那樣嚴格的效能保證。近年也有許多研究，嘗試設計電路較淺的「早期容錯」版本相位估計。

@section 和 AI 一起做：讓 AI 解釋公式，你負責數值驗證
QFT 和相位估計的公式符號很多，很容易在細節出錯：正負號、2π 的位置、位元順序、要不要 SWAP。這是 AI 也常出錯的地方，所以「數值驗證」特別重要。

**請 AI 用矩陣定義實作 QFT，再和 FFT 比對**
```
請用 NumPy 建立 n 個量子位元的 QFT 矩陣（N×N，元素 e^(2πi·jk/N)/√N），
並驗證：
1. 它是么正矩陣（F 的共軛轉置乘 F 等於單位矩陣）
2. QFT 作用在任意向量 v 上，結果等於 np.fft.ifft(v) × √N
   （請說明為什麼是 ifft 而不是 fft）
3. n=1 時等於 H 閘
```
第二點很關鍵：NumPy 的 `fft` 用的指數符號是負的，而 QFT 的定義是正的，所以對應的是 `ifft` 乘上正規化常數。這種**慣例差異**是 AI 和人類都常搞混的地方。讓程式來檢查，比爭論誰的記憶正確可靠得多。

**請 AI 寫相位估計的模擬，並測試「非精確」的相位**
請 AI 模擬相位估計，用 φ = 0.25（可以用 2 位元精確表示）和 φ = 0.3（不行）各跑一次，觀察測量結果的分布。φ = 0.3 時，你會看到結果集中在 0.3 附近，但不是 100% 集中。這幫助你理解相位估計是一個**機率性的近似**。

**用 AI 準備「量子化學應用」的閱讀**
量子相位估計最重要的應用是化學。可以請 AI：「請用高中化學程度，解釋為什麼分子的基態能量很難用一般電腦算，以及相位估計怎麼幫忙。」然後追問：「目前（2025 年後）的資源估計大概需要多少邏輯量子位元？請附上來源。」記得到原始論文確認 AI 引用的數字。

@section 常見疑問：QFT 和相位估計
**問：QFT 和一般的快速傅立葉轉換（FFT）有什麼不同？**
數學上做的是同一種轉換，差別在「輸入和輸出放在哪裡」。FFT 處理 N 個數字，需要約 N log N 次運算，而且你能讀到全部輸出。QFT 把 N = 2ⁿ 個數字存在 n 個量子位元的機率幅裡，只要約 n² 個閘就能完成轉換，但你**讀不到全部輸出**，測量只會給你一個結果。所以 QFT 不能拿來加速一般的訊號處理，它只在「輸出分布本身就藏著答案」時才有用，例如週期尋找。

**問：為什麼 QFT 的電路最後要把量子位元順序反過來？**
QFT 的標準電路，計算完之後的位元順序剛好和定義相反（最高位變成最低位）。最後加一排 SWAP 閘把順序翻正。實務上很多實作會省略這些 SWAP，改成在讀結果時把位元順序反過來，這樣可以省下閘數。

**問：相位估計的精確度由什麼決定？**
由「計數暫存器」的量子位元數 t 決定：t 個位元能表示 2ᵗ 種相位，精確度大約是 1/2ᵗ。如果真實相位剛好是 k/2ᵗ，結果會 100% 準確；否則測量結果會集中在最接近的幾個值附近，成功率至少約 81%（4/π²）。想提高成功率，可以多加幾個計數位元，或重複執行取多數。

**問：相位估計需要 U 的 2ᵏ 次方，這不是很貴嗎？**
是的，這是相位估計最主要的成本。如果 U 只能一次一次重複執行，U^(2ᵗ) 就要執行 2ᵗ 次，效率會跟著消失。相位估計之所以在 Shor 演算法中有效，是因為模指數 aˣ mod N 可以用「反覆平方」的方式高效計算 a 的 2ᵏ 次方。在量子化學中，則需要模擬 e^(−iHt) 很長時間，這是容錯量子化學計算成本最高的部分。

**問：現在還有哪些相位估計的變形？**
早期的容錯硬體量子位元很少，所以有人發展出**迭代相位估計**：只用一個輔助量子位元，一位一位地估計相位。另外還有**貝氏相位估計**和 **QCELS**、**robust phase estimation** 等方法，目的都是減少需要的量子位元數或電路深度，讓相位估計能在早期容錯硬體上執行。2024–2026 年 Quantinuum 和 Google 都用這類方法做過小型分子能量估計的實驗。

@section 延伸練習：動手做 QFT
**練習一：驗證 QFT 是么正的**
用範例的 qft_matrix 函式建出 n = 3 的矩陣 F，計算 F 乘以 F 的共軛轉置，確認結果是單位矩陣（誤差小於 1e−9）。這能驗證你的 QFT 實作沒有寫錯。

**練習二：週期越短，峰越少**
準備一個「每隔 r 個位置為 1」的狀態（例如 N = 16，r = 4，位置 0、4、8、12 有相同機率幅），做 QFT 後印出機率。你會看到峰剛好出現在 N/r 的倍數。把 r 改成 2、8 再試一次，這正是 Shor 演算法讀出週期的方法。

**練習三：相位不剛好時的分布**
在範例的相位估計中，把相位設成 0.3（不是 1/8 的倍數），印出所有測量結果的機率，觀察最高的峰在哪裡、旁邊的峰有多高。再把計數位元從 3 增加到 6，看看分布怎麼變窄。

@section 觀念串連：相位估計是很多演算法的心臟
相位估計看起來只是一個「讀出特徵值」的工具，但它其實是許多重要量子演算法的共同核心。理解這一點，能讓你在後面的課程中更快抓住重點。

**Shor 演算法**（第 94 課）：把模乘法看成一個么正運算 U，它的特徵值相位剛好藏著週期 r 的資訊。相位估計讀出這個相位，再用連分數找出 r。所以 Shor 演算法本質上就是「相位估計加上一個巧妙的 U」。

**量子化學**：分子的能量就是哈密頓量的特徵值。把 e^(−iHt) 當作 U，相位估計就能直接讀出能量。這是容錯時代最被看好的應用之一，而第 98 課的 VQE，常被用來先準備一個接近基態的初始狀態，再交給相位估計做精確計算。

**HHL 線性方程演算法**：用相位估計找出矩陣的特徵值，再對每個特徵值做「除法」，就能得到 A⁻¹b 的量子態。它曾被視為量子機器學習的基礎，但後來的去量子化研究（第 100 課）指出，它的優勢需要很多前提條件，例如資料載入、矩陣的稀疏性和條件數。

**量子計數**：結合 Grover 迭代和相位估計，可以估計搜尋問題中目標的數量。

所以，當你看到一個新的量子演算法時，可以先問：它是不是在用相位估計？如果是，U 是什麼？U 的高次方能不能有效實作？初始狀態要怎麼準備？這三個問題往往就決定了演算法的實際可行性。

@section 動動腦：判斷看看
**題一**：QFT 作用在 1 個量子位元上，等同於哪個量子閘？
→ H 閘（阿達瑪閘）。

**題二**：QFT 只需要約 n² 個閘，古典 FFT 需要約 n·2ⁿ 步，為什麼不能用 QFT 來加速一般的訊號處理？
→ 輸入資料要載入成量子態（成本約 N），輸出的機率幅也無法全部讀出，只能透過測量取樣。

**題三**：量子相位估計想要多一個位元的精確度，受控 U 的執行次數會怎麼變？
→ 大約加倍。

**題四**：為什麼今天的量子化學實驗多用 VQE 而不是相位估計？
→ 相位估計的電路很深，需要容錯量子電腦；VQE 電路較淺，適合有雜訊的硬體。

**題五**：近似 QFT 省略了哪些閘？為什麼影響不大？
→ 省略旋轉角度非常小的受控相位閘；它們對結果的貢獻極小，省略後在雜訊硬體上甚至可能更好。

@section 本課重點整理
- **傅立葉轉換**：找出資料中的週期（頻率）；核心是「吻合就加強、不吻合就抵消」的干涉。
- **QFT**：把 |x⟩ 轉成帶有規律相位的均勻疊加；n=1 時就是 H 閘。
- **乘積形式**：QFT 的輸出可拆成各量子位元的獨立狀態，因此能用 H 與受控相位旋轉實現，約 n² 個閘。
- **近似 QFT**：省略極小旋轉，閘數降到約 n log n。
- **不能直接加速 FFT**：資料載入與結果讀出都是瓶頸；QFT 適合「輸入量子產生、只要全域性質」的情況。
- **量子相位估計**：讀出么正操作特徵值的相位；是 Shor、量子化學、HHL 的核心；需要深電路與容錯。
- **注意慣例**：QFT 的正負號對應 NumPy 的 ifft。

@term 傅立葉轉換
把資料分解成不同頻率成分、找出週期性的數學轉換（Fourier Transform）。
@term 量子傅立葉轉換
作用在量子態機率幅上的離散傅立葉轉換，約需 n² 個量子閘（Quantum Fourier Transform, QFT）。
@term 受控相位旋轉閘
控制位元為 1 時在目標位元 |1⟩ 上加上特定相位的雙量子位元閘（Controlled Phase Rotation）。
@term 量子相位估計
估計么正操作特徵值相位的量子演算法，是 Shor 與量子化學演算法的核心（Quantum Phase Estimation, QPE）。
@term 特徵向量
被線性操作作用後只改變倍數（量子中為相位）、方向不變的向量（Eigenvector）。
@term 近似 QFT
省略旋轉角度極小之受控相位閘的 QFT 版本，閘數更少且精確度幾乎不變（Approximate QFT）。
