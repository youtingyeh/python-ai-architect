@section 開場：第一批證明「量子比較快」的演算法
學完量子位元、量子閘、糾纏與測量之後，終於可以來看真正的**量子演算法**了。這一課介紹兩個歷史上很重要的演算法：

- **Deutsch–Jozsa 演算法**（1992）：第一個證明量子電腦在某些問題上，比任何確定性古典演算法都快很多的例子；
- **Bernstein–Vazirani 演算法**（1993）：用一次查詢就找出一個隱藏的位元字串。

老實說，這兩個演算法解決的問題**沒有什麼實用價值**，它們是刻意設計的「玩具問題」。但它們非常適合用來學習量子演算法的核心技巧：
- **相位回踢**（phase kickback）：把答案「藏」在相位裡；
- **干涉**：讓錯誤答案互相抵消；
- **查詢複雜度**：量子優勢最乾淨的衡量方式。

學會這些技巧，下一課的 Grover 搜尋、之後的 Shor 演算法就會容易理解得多。

@section 黑盒子與查詢複雜度
**黑盒子（Oracle）**
許多量子演算法的問題設定是這樣的：有一個**黑盒子**函數 f，你看不到它的內部，只能輸入 x 問它 f(x) 是多少。這個黑盒子叫做 **oracle**（預言機）。問題是：**最少要問幾次，才能知道 f 的某個性質？**

這種衡量方式叫做**查詢複雜度**（query complexity）。它的好處是可以嚴格證明量子和古典之間的差距；缺點是，真實問題裡的函數通常不是黑盒子，所以查詢上的優勢不一定能轉成實際速度上的優勢。

**量子版的黑盒子**
量子電腦不能直接把 x 變成 f(x)，因為量子操作必須是**可逆**的（么正矩陣都有反矩陣），而 f 可能不可逆。標準作法是使用一個額外的量子位元：
U_f |x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

其中 ⊕ 是 XOR（互斥或）。輸入 x 保持不變，答案被 XOR 到額外的量子位元上，這樣整個操作就是可逆的。

**一次查詢，所有輸入？**
如果把輸入設成所有 x 的疊加（對每個量子位元做 H），一次查詢就會在疊加狀態中「算出」所有 f(x)。但第 90 課說過，測量只能得到其中一個結果。所以關鍵不在「同時計算」，而在於**怎麼設計干涉，讓我們想要的全域性質，在測量時清楚地顯現出來**。

@section 相位回踢：把答案藏進相位
這是本課最重要的技巧。

**把額外的量子位元設成 |−⟩**
如果額外的量子位元是 |−⟩ = (|0⟩ − |1⟩)/√2，那麼：
- 若 f(x) = 0：|0⟩ ⊕ 0 = |0⟩、|1⟩ ⊕ 0 = |1⟩，額外量子位元不變，仍是 |−⟩；
- 若 f(x) = 1：|0⟩ 和 |1⟩ 互換，變成 (|1⟩ − |0⟩)/√2 = −|−⟩。

所以：
U_f |x⟩|−⟩ = (−1)^f(x) |x⟩|−⟩

額外的量子位元完全沒變，但輸入的 |x⟩ 前面多了一個**正負號**（相位）！答案 f(x) 就這樣從額外量子位元「回踢」到輸入的相位上。這就叫做**相位回踢**（phase kickback）。

**為什麼這很有用？**
第 87 課說過，單一個整體相位測不出來；但在**疊加**狀態中，不同項之間的**相對相位**是可以透過干涉觀察到的。所以，當輸入是許多 x 的疊加時，每一項都帶著自己的 (−1)^f(x)，再做一次 H 閘讓它們干涉，就能把 f 的全域性質轉換成可測量的結果。

**生活中的比喻**
想像合唱團每個人唱同一個音，但有些人被要求「反相」唱（聲波正好相反）。單獨聽一個人，你分不出他是正相還是反相；但所有人一起唱時，反相的人會抵消正相的人的聲音。透過聽「總音量」，你就能知道正相和反相的人數是否相等。量子演算法做的就是類似的事。

@section Deutsch–Jozsa：常數還是平衡？
**問題**
有一個黑盒子函數 f，輸入是 n 個位元，輸出是 0 或 1。保證 f 是以下兩種之一：
- **常數**（constant）：所有輸入的輸出都相同（全是 0，或全是 1）；
- **平衡**（balanced）：剛好一半的輸入輸出 0，另一半輸出 1。

請判斷 f 是哪一種。

**古典作法**
最壞情況下，你問了一半的輸入（2ⁿ⁻¹ 個）都得到 0，還是不能確定，因為剩下的可能全是 1（平衡）或全是 0（常數）。所以確定性的古典演算法，最壞要問 **2ⁿ⁻¹ + 1 次**。n = 50 時，這是天文數字。

**量子作法：只要問一次**
1. 準備 n 個量子位元在 |0⟩，一個額外量子位元在 |1⟩；
2. 對所有量子位元做 H：輸入變成所有 x 的均勻疊加，額外量子位元變成 |−⟩；
3. 呼叫一次黑盒子 U_f：透過相位回踢，每一項變成 (−1)^f(x)|x⟩；
4. 再對 n 個輸入量子位元做 H；
5. 測量 n 個輸入量子位元。

**結果**
- 如果 f 是**常數**：所有項的相位都相同，第二次 H 之後，它們全部建設性干涉回到 |00…0⟩，**100% 測到全 0**；
- 如果 f 是**平衡**：一半是 +、一半是 −，回到 |00…0⟩ 的機率幅剛好抵消成 0，**永遠不會測到全 0**。

所以：測到全 0 就是常數，否則就是平衡。**只需要一次查詢。**

**誠實的評估**
這個指數級的優勢有一個前提：要求**百分之百確定**。如果允許一點點出錯的機率，古典的**隨機演算法**只要隨機問 10 次左右，如果全部相同就說是常數，出錯的機率小於千分之一。所以 Deutsch–Jozsa 的優勢，在實務上並沒有那麼戲劇性。這正好提醒我們：評估量子優勢時，一定要和**最好的**古典演算法比較，包括隨機演算法。第 101 課會反覆用到這個原則。

@section Bernstein–Vazirani：一次找出秘密字串
**問題**
黑盒子裡藏著一個 n 位元的秘密字串 s。函數定義是：
f(x) = s · x（mod 2）

也就是把 x 和 s 逐位元相乘後加總，再取除以 2 的餘數。例如 s = 101、x = 111，s · x = 1 + 0 + 1 = 2，mod 2 是 0。

請找出 s。

**古典作法**
每次查詢只能得到一個位元的資訊。最聰明的方法是依序輸入 100…0、010…0、…、000…1，每次得到 s 的一個位元，總共需要 **n 次**查詢。這已經是最好的，無法更少。

**量子作法：一次就夠**
電路和 Deutsch–Jozsa **完全一樣**！唯一的差別是黑盒子裡面的函數不同。結果是：
- 第二次 H 之後，狀態剛好就是 |s⟩；
- 測量 n 個量子位元，直接得到秘密字串 s，**機率 100%**。

**為什麼會這樣？**
因為 n 個量子位元的 H 閘有一個漂亮的性質：
H⊗ⁿ |s⟩ = (1/√2ⁿ) Σₓ (−1)^(s·x) |x⟩

也就是說，H 閘會把 |s⟩ 變成「每一項的相位是 (−1)^(s·x)」的疊加。而相位回踢製造出來的狀態，正好就是這個形式！H 閘是自己的反操作（做兩次等於沒做），所以再做一次 H，就變回 |s⟩。

**優勢有多大？**
n 次 vs 1 次，是**多項式**（線性）的優勢，不是指數級的；但這次即使古典使用隨機演算法也無法更好，因為每次查詢最多只提供一個位元的資訊。

**這些技巧在哪裡還會出現？**
「H → 黑盒子（相位回踢）→ H → 測量」這個模式，是許多量子演算法的骨架。H⊗ⁿ 本質上是一種「傅立葉轉換」（在 0、1 世界裡的版本）。第 93 課的**量子傅立葉轉換**會把這個想法推廣，它是 Shor 演算法的核心。

@section 和 AI 一起做：用 AI 生成並驗證演算法電路
這兩個演算法的電路很規律，正好練習「讓 AI 生成程式碼，自己負責驗證」的工作流程。

**請 AI 寫一個通用的模擬器**
```
請用純 NumPy（不要用 Qiskit）寫 Bernstein–Vazirani 的模擬：
- 函式 bv(secret: str) 回傳測量結果的機率分布（dict）
- 黑盒子用相位回踢的形式實作：直接把 (−1)^(s·x) 乘到對應的機率幅上
- 不要硬編碼答案，要真的做 H⊗ⁿ → 相位 → H⊗ⁿ
- 附上測試：對所有 3 位元的秘密字串，結果都是機率 1 的 s
```
最後一行很重要：**要求 AI 附上會失敗的測試**。如果 AI 偷懶，直接回傳 {secret: 1.0}，測試雖然會過，但你看程式碼就會發現它沒有真的做 H 閘。這是和 AI 協作時常見的陷阱：**測試通過不代表實作正確**，你要檢查實作是否真的做了題目要求的事。

**請 AI 擔任「古典對手」**
問 AI：「對於 Deutsch–Jozsa，如果允許 1% 的錯誤率，古典隨機演算法需要問幾次？請推導。」然後自己檢查推導：如果 f 是平衡的，隨機問 k 次全部相同的機率約是 2 × (1/2)ᵏ。讓 AI 扮演質疑量子優勢的角色，是培養批判思考的好方法。

**在 Qiskit 上跑**
等純 NumPy 版本正確了，再請 AI 把它改寫成 Qiskit 電路，用模擬器執行並比對結果。記得檢查第 89 課提到的位元順序問題：Qiskit 輸出的字串可能是反過來的。

@section 動動腦：判斷看看
**題一**：Deutsch–Jozsa 演算法測量後得到 000，f 是什麼類型？
→ 常數函數。平衡函數回到全 0 的機率幅剛好抵消為 0。

**題二**：相位回踢需要把額外的量子位元設成什麼狀態？
→ |−⟩ = (|0⟩ − |1⟩)/√2。這樣 f(x) = 1 時會在輸入上產生負號，而額外量子位元本身不變。

**題三**：如果允許少量錯誤機率，Deutsch–Jozsa 還有指數級的量子優勢嗎？
→ 沒有。古典隨機演算法只要問固定的少數幾次，就能把錯誤率壓得很低。

**題四**：Bernstein–Vazirani 的秘密字串 s = 1101，量子演算法要查詢幾次？古典確定性演算法呢？
→ 量子 1 次；古典需要 4 次（n 次）。

**題五**：量子黑盒子為什麼寫成 |x⟩|y⟩ → |x⟩|y ⊕ f(x)⟩，而不是直接 |x⟩ → |f(x)⟩？
→ 量子操作必須可逆；f 不一定可逆，保留 x 並把結果 XOR 到額外位元上，整體就可逆了。

@section 本課重點整理
- **黑盒子與查詢複雜度**：用查詢次數嚴格比較量子與古典，但不一定等於實際速度優勢。
- **量子黑盒子**：U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩，確保可逆。
- **相位回踢**：額外量子位元設為 |−⟩，答案變成輸入上的 (−1)^f(x) 相位。
- **Deutsch–Jozsa**：一次查詢判斷常數或平衡；但若允許錯誤，古典隨機演算法也很快。
- **Bernstein–Vazirani**：一次查詢找出秘密字串，古典需 n 次；靠 H⊗ⁿ 把相位轉回字串。
- **核心模式**：H → 黑盒子 → H → 測量，是傅立葉轉換思想的雛形。
- **評估量子優勢要和最好的古典演算法比較**，包括隨機演算法。

@term Oracle（黑盒子）
只能透過查詢輸入輸出來使用的函數，常用於量子演算法的問題設定。
@term 查詢複雜度
解決問題所需呼叫黑盒子的次數，可嚴格比較量子與古典（Query Complexity）。
@term 相位回踢
透過受控操作，讓目標位元上的效果變成控制位元上的相位（Phase Kickback）。
@term Deutsch–Jozsa 演算法
一次查詢判斷黑盒子函數是常數或平衡的量子演算法（1992）。
@term Bernstein–Vazirani 演算法
一次查詢找出黑盒子中隱藏位元字串的量子演算法（1993）。
@term 可逆計算
每個輸出都能唯一對應回輸入的計算；量子閘（么正操作）必然可逆。
