@section 複數：多了一個方向的數
**為什麼需要複數？**
第 85 課說過，量子計算的力量來自**干涉**：不同路徑的機率幅會互相加強或抵消。如果機率幅只能是正數，就只能加強、不能抵消。如果允許正負號，就能抵消了。而**複數**比正負號更進一步：它讓機率幅不只有「方向相同或相反」兩種關係，而是可以有**任意角度**的關係。

**複數長什麼樣子？**
一個複數寫成 a + bi，其中 a 和 b 是一般的實數，i 是一個特別的數，規定 i × i = −1。
- a 叫做**實部**；
- b 叫做**虛部**。

「虛數」這個名字很容易讓人以為它是假的、不存在的。其實換個方式想就清楚了：**複數就是平面上的一個點**。把實部當作橫座標、虛部當作縱座標，3 + 4i 就是平面上座標 (3, 4) 的那個點。

**兩個重要的量**
- **大小**（絕對值）：這個點離原點多遠。3 + 4i 的大小是 √(3² + 4²) = 5；
- **角度**（相位）：這個點和正橫軸夾多少角度。

在量子計算裡，**機率幅的大小決定機率，機率幅的角度決定干涉的方式**。兩個機率幅相加時：角度相同，大小就相加（加強）；角度相差 180 度，就互相抵消。

**共軛複數**
把 a + bi 的虛部變號，得到 a − bi，這叫做**共軛複數**。它有一個很好用的性質：一個複數乘上自己的共軛，會得到大小的平方，而且一定是正的實數：
(3 + 4i)(3 − 4i) = 9 + 16 = 25 = 5²

量子計算裡計算機率時，就是用這個方法：**機率 = 機率幅 × 機率幅的共軛 = 機率幅大小的平方**。

**Python 直接支援複數**
在 Python 裡，虛數單位寫成 `j`（工程上的習慣）：
```python
z = 3 + 4j
print(abs(z))            # 5.0，大小
print(z.conjugate())     # (3-4j)，共軛
print(z * z.conjugate()) # (25+0j)，大小的平方
```

@section 向量：量子狀態的身分證
**狀態就是一個向量**
一個量子位元的狀態，可以用**兩個複數**組成的向量來表示：
- 第一個數是「測到 0」的機率幅；
- 第二個數是「測到 1」的機率幅。

例如：
- 確定是 0 的狀態：(1, 0)
- 確定是 1 的狀態：(0, 1)
- 一半一半的疊加：(1/√2, 1/√2)

**規則：機率加起來等於 1**
因為測量的結果一定是 0 或 1 其中之一，兩個機率加起來必須是 1。也就是說，兩個機率幅**大小的平方**相加要等於 1。這叫做**歸一化**（normalization）。

檢查 (1/√2, 1/√2)：(1/√2)² + (1/√2)² = 1/2 + 1/2 = 1，符合規則。

**多個量子位元：向量會變長**
兩個量子位元有 4 種可能的結果（00、01、10、11），所以狀態向量有 4 個數。三個量子位元有 8 個數，n 個量子位元有 2ⁿ 個數。

這就是量子計算常被提到的「指數級」：**描述 n 個量子位元的狀態，需要 2ⁿ 個複數**。50 個量子位元就需要大約一千兆（10¹⁵）個複數，用一般電腦儲存要好幾 PB 的記憶體。這也是為什麼用一般電腦模擬大型量子電腦非常困難。

但要注意一個常見的誤解：這不代表量子電腦能「儲存」2ⁿ 個答案讓你讀取。測量時你只會得到 n 個位元的結果。這些機率幅的用處，是讓演算法能在計算過程中**利用干涉**，而不是讓你直接讀出來。

@section 狄拉克符號：物理學家的速記法
物理學家發明了一種簡潔的寫法，叫做**狄拉克符號**（Dirac notation），也叫「bra-ket 符號」。量子計算的論文和教材幾乎都用它，所以一定要看得懂。

**ket：直立的向量**
符號 |名字⟩ 叫做「ket」，代表一個（直立的）狀態向量：
- |0⟩ 代表 (1, 0)，確定是 0 的狀態；
- |1⟩ 代表 (0, 1)，確定是 1 的狀態；
- |ψ⟩（讀作「ket psi」）通常代表一個一般的狀態。

所以疊加狀態可以寫成：
|ψ⟩ = α|0⟩ + β|1⟩

意思是「α 倍的 |0⟩ 加上 β 倍的 |1⟩」，也就是向量 (α, β)。其中 α、β 是複數，而且 |α|² + |β|² = 1。

**兩個常見的疊加狀態**
它們太常用了，所以有自己的名字：
- |+⟩ = (|0⟩ + |1⟩)/√2，也就是 (1/√2, 1/√2)
- |−⟩ = (|0⟩ − |1⟩)/√2，也就是 (1/√2, −1/√2)

這兩個狀態測量時，得到 0 和 1 的機率**都是一半一半**，用測量完全分辨不出來。但它們是不同的狀態：差別就在第二個機率幅的**正負號**。下一課會看到，只要先經過一個量子閘再測量，就能完美地分辨它們。這正是「相位」雖然不能直接測量、卻非常重要的原因。

**bra：躺平的向量**
符號 ⟨名字| 叫做「bra」，代表把 ket **轉成橫的，並把每個數取共軛**。例如 |ψ⟩ = (α, β)，那麼 ⟨ψ| = (α 的共軛, β 的共軛) 排成一列。

**bra 和 ket 合起來：內積**
把 bra 和 ket 放在一起，⟨φ|ψ⟩，就是兩個向量的**內積**：對應的數相乘再相加（bra 那邊的數取共軛）。名稱的由來也很有趣：英文 bracket（括號）拆成 bra 和 ket。

內積的大小，代表兩個狀態有多「像」：
- ⟨0|1⟩ = 0：|0⟩ 和 |1⟩ 完全不同（正交）；
- ⟨0|0⟩ = 1：任何歸一化的狀態和自己的內積都是 1；
- ⟨+|−⟩ = 0：|+⟩ 和 |−⟩ 也是完全不同的狀態。

而**測量的機率**也可以用內積表示：狀態 |ψ⟩ 測到 0 的機率，是 ⟨0|ψ⟩ 大小的平方。

@section 矩陣：量子閘的真面目
**量子閘就是矩陣**
在一般電腦裡，邏輯閘（AND、OR、NOT）會改變位元的值。在量子電腦裡，**量子閘**會改變狀態向量，而做法就是**矩陣乘法**：新的狀態 = 矩陣 × 舊的狀態。

一個量子位元的狀態是 2 個數的向量，所以作用在一個量子位元上的量子閘，是 2×2 的矩陣。

**例子：X 閘（量子版的 NOT）**
X 閘的矩陣是：
```
X = [[0, 1],
     [1, 0]]
```
把它作用在 |0⟩ = (1, 0) 上：
- 新的第一個數 = 0×1 + 1×0 = 0
- 新的第二個數 = 1×1 + 0×0 = 1

結果是 (0, 1) = |1⟩。X 閘把 0 變成 1，就像 NOT 閘一樣。作用在疊加狀態 α|0⟩ + β|1⟩ 上，它會把兩個機率幅**交換**，變成 β|0⟩ + α|1⟩。

**量子閘的特殊規則：么正**
不是任何矩陣都能當作量子閘。量子閘必須是**么正矩陣**（unitary matrix）。這個名詞聽起來很嚇人，但它的意思很直覺：

**么正矩陣不會改變向量的長度**。

為什麼需要這個規則？因為狀態向量的長度（各機率幅大小平方的總和）必須永遠等於 1，也就是機率總和必須是 1。如果量子閘會改變長度，經過它之後機率加起來可能變成 0.7 或 1.3，這在物理上是不可能的。

么正矩陣還有另一個重要的性質：**它一定可以反轉**。每個量子閘都有一個「反向操作」，能把狀態變回原來的樣子。這和一般電腦很不一樣：一般電腦的 AND 閘是不可逆的（輸出 0 時，你不知道輸入是 00、01 還是 10）。量子計算在測量之前，每一步都是可逆的。

**用 Python 驗證**
```python
import numpy as np
X = np.array([[0, 1], [1, 0]], dtype=complex)
ket0 = np.array([1, 0], dtype=complex)
print(X @ ket0)                                 # [0, 1]，也就是 |1⟩
print(np.allclose(X.conj().T @ X, np.eye(2)))   # True：X 是么正矩陣
```
最後一行是檢查么正的標準方法：矩陣的「共軛轉置」乘上它自己，會得到單位矩陣。

@section 和 AI 一起做：讓 AI 陪你練數學
量子計算的數學，最需要的是**大量練習**，而 AI 是很好的練習夥伴。但數學計算是 AI 容易出錯的地方之一，所以要建立「**AI 出題、AI 講解、你用程式驗證**」的習慣。

**請 AI 出練習題**
```
我正在學量子計算需要的線性代數。請出 5 題練習題，難度由淺到深：
1. 複數的大小與共軛
2. 檢查一個量子狀態是否歸一化
3. 計算兩個狀態的內積
4. 2×2 矩陣乘上狀態向量
5. 判斷一個矩陣是否為么正矩陣
先只給題目，等我作答後再給詳解。
```
「先只給題目」很重要，否則答案會直接出現在題目下方，你就失去了自己思考的機會。

**用 Python 驗證 AI 的答案**
AI 給詳解之後，不要只是點頭，而是用本課的 Python 程式**自己算一次**。例如 AI 說「這個矩陣是么正的」，就用 `np.allclose(M.conj().T @ M, np.eye(2))` 檢查。如果結果和 AI 說的不一樣，請 AI 重新檢查它的計算過程。這個過程本身就是很好的學習：你會發現 AI 常在哪些地方出錯（例如忘記取共軛）。

**請 AI 換個方式解釋**
如果某個概念看不懂，例如「為什麼量子閘必須是么正矩陣」，可以請 AI：
- 用三種不同的比喻解釋；
- 先舉一個「不是么正」的矩陣，示範它會讓機率總和變得不等於 1。

反例往往比正面的說明更容易讓人理解。

@section 常見疑問：數學要學到什麼程度？
**問：我高中數學不太好，還學得會量子計算嗎？**
可以。量子計算入門真正需要的數學，比想像中少：複數的加減乘、向量與矩陣的乘法、以及「長度為 1」的概念。這一課已經涵蓋了大部分。微積分在量子機器學習的梯度部分會用到一點，但我們都會用程式代替手算。比數學程度更重要的，是**願意一步一步驗算**的習慣。

**問：為什麼量子力學一定要用複數？用實數不行嗎？**
這是物理學家也認真研究過的問題。2021 到 2022 年，有幾個團隊設計實驗，證明在某些糾纏實驗中，「只用實數」的量子理論會給出和實驗不符的預測。也就是說，複數不只是數學上的方便，而是描述自然所必需的。直覺上，複數讓機率幅可以有「方向」（相位），不同路徑的機率幅才能互相抵消或加強。

**問：狄拉克符號和一般的向量寫法，哪一個比較好？**
兩者描述的是同一件事。狄拉克符號的好處是簡潔：寫 |0⟩ 比寫 [1, 0] 更容易看出意義，而且量子位元一多，寫成 |0101⟩ 比寫一個 16 維的向量清楚得多。寫程式時則一定用向量和矩陣。建議兩種都熟悉，看到 |ψ⟩ 時能在腦中換成一個直的向量，看到 ⟨ψ| 時換成一個橫的、取了共軛的向量。

**問：么正矩陣為什麼這麼重要？**
因為量子系統在沒有被測量時的演化，一定是么正的。么正矩陣保證兩件事：一是**機率總和永遠是 1**，不會憑空多出或少掉機率；二是**操作一定可以反過來**，所以量子計算本質上是可逆計算。第 91 課設計量子黑盒子時，就會看到「可逆」這個限制帶來的影響。

@section 延伸練習：用程式建立直覺
讀完這一課，建議動手做三個小練習，每個大約十分鐘：

**練習一：複數的旋轉**
寫一個迴圈，把複數 1 反覆乘上 e^(iπ/4)，印出每一步的實部和虛部。你會看到它在單位圓上每次轉 45 度，八次後回到原點。這個「乘上 e^(iφ) 就是旋轉」的直覺，在第 93 課的量子傅立葉轉換會一再用到。

**練習二：驗證機率守恆**
隨機產生一個長度為 1 的二維複數向量，再隨機挑幾個么正矩陣（例如 H、X、以及旋轉矩陣）依序乘上去，每一步都計算機率總和。無論做幾次，總和都應該是 1（在浮點數誤差範圍內）。再試試乘上一個**不是**么正的矩陣，看看機率總和怎麼被破壞。

**練習三：內積與測量機率**
計算 |⟨+|ψ⟩|² 和 |⟨−|ψ⟩|²，驗證兩者加起來等於 1。這代表「在 X 基底測量」也是一個合法的測量，第 90 課會正式介紹。

@section 動動腦：判斷看看
**題一**：狀態 (0.6, 0.8) 是一個合法的量子位元狀態嗎？
→ 是。0.6² + 0.8² = 0.36 + 0.64 = 1，符合歸一化；測到 0 的機率是 0.36，測到 1 的機率是 0.64。

**題二**：|+⟩ 和 |−⟩ 測量時的機率都是一半一半，它們是同一個狀態嗎？
→ 不是。兩者第二個機率幅的正負號不同，內積為 0，是完全不同（正交）的狀態；先經過適當的量子閘再測量就能分辨。

**題三**：描述 20 個量子位元的完整狀態，需要多少個複數？
→ 2²⁰ = 1,048,576 個，大約一百萬個。

**題四**：為什麼量子閘必須是么正矩陣？
→ 么正矩陣不改變向量長度，才能保持機率總和永遠等於 1；而且么正矩陣一定可以反轉。

**題五**：複數 1 + i 的大小是多少？乘上自己的共軛會得到什麼？
→ 大小是 √2；乘上共軛 1 − i 得到 2，正好是大小的平方。

@section 本課重點整理
- **量子計算的語言是線性代數**：狀態是向量、量子閘是矩陣、計算就是矩陣乘法。
- **複數**：平面上的點，有大小與角度；機率幅的大小決定機率，角度決定干涉方式。
- **機率 = 機率幅大小的平方**，可用「乘上共軛」計算。
- **狀態向量**：一個量子位元 2 個複數，n 個量子位元 2ⁿ 個複數，且要歸一化。
- **狄拉克符號**：ket |ψ⟩ 是直立向量，bra ⟨ψ| 是取共軛後的橫向量，⟨φ|ψ⟩ 是內積。
- **|+⟩ 與 |−⟩**：測量機率相同但相位不同，是不同的狀態。
- **量子閘必須是么正矩陣**：保持長度（機率總和為 1）、一定可逆。

@term 複數
形如 a + bi 的數，i × i = −1；可視為平面上的點，具有大小與角度。
@term 共軛複數
把複數虛部變號得到的數；複數乘上其共軛等於大小的平方。
@term 歸一化
量子狀態各機率幅大小平方的總和必須等於 1 的規則（Normalization）。
@term 狄拉克符號
用 |ψ⟩（ket）與 ⟨ψ|（bra）表示量子狀態的記號系統，又稱 bra-ket 符號。
@term 內積
兩個向量對應元素相乘再相加（bra 側取共軛），表示兩個狀態相似的程度。
@term 正交
兩個狀態的內積為 0，代表它們可以被完美分辨。
@term 么正矩陣
共軛轉置乘以自身等於單位矩陣的矩陣（Unitary Matrix），不改變向量長度且必定可逆。
@term 量子閘
作用在量子狀態上的操作，數學上以么正矩陣表示。
