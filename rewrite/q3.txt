@section 開場：一加一大於二
前兩課研究的都是**單一個**量子位元。如果量子電腦只有這些，它的能力其實很有限：單一量子位元的行為，用一般電腦很容易就能模擬。量子計算真正的威力，來自**多個量子位元之間的關係**，特別是一種叫做**糾纏**（entanglement）的現象。

愛因斯坦曾經對糾纏非常不以為然，稱它為「**鬼魅般的超距作用**」。他無法接受兩個粒子之間存在這種奇特的關聯。但後來的實驗一再證實糾纏是真實的，2022 年的諾貝爾物理學獎，就頒給了用實驗驗證糾纏的三位科學家。

這一課會介紹：
- 怎麼用數學描述多個量子位元（**張量積**）；
- 最重要的雙量子位元閘：**CNOT 閘**；
- 怎麼製造糾纏，以及最有名的糾纏狀態：**貝爾態**；
- 糾纏的特性與常見誤解；
- 一個影響深遠的定理：**量子狀態不能被複製**。

@section 張量積：把多個量子位元組合起來
**兩個量子位元的狀態**
第 87 課說過，兩個量子位元有 4 種可能的測量結果：00、01、10、11，所以狀態向量有 4 個機率幅：
|ψ⟩ = a|00⟩ + b|01⟩ + c|10⟩ + d|11⟩

其中 |a|² + |b|² + |c|² + |d|² = 1。|01⟩ 的意思是「第一個量子位元是 0、第二個是 1」。

**張量積：組合兩個獨立的量子位元**
如果兩個量子位元各自獨立，第一個是 (α₁, β₁)、第二個是 (α₂, β₂)，那麼合起來的狀態，就是把每一對機率幅**相乘**：
- |00⟩ 的機率幅 = α₁ × α₂
- |01⟩ 的機率幅 = α₁ × β₂
- |10⟩ 的機率幅 = β₁ × α₂
- |11⟩ 的機率幅 = β₁ × β₂

這個組合方式叫做**張量積**（tensor product），符號是 ⊗。例如 |0⟩ ⊗ |1⟩ 就寫成 |01⟩。

在 NumPy 裡，張量積用 `np.kron` 計算：
```python
import numpy as np
ket0 = np.array([1, 0]); ket1 = np.array([0, 1])
print(np.kron(ket0, ket1))  # [0 1 0 0]，也就是 |01⟩
```

**一個直覺的例子**
兩個量子位元都是 |+⟩（各自一半一半），合起來就是：
|+⟩ ⊗ |+⟩ = (|00⟩ + |01⟩ + |10⟩ + |11⟩)/2

四種結果的機率都是 1/4。這很合理：兩枚獨立的公正硬幣，四種組合的機率都一樣。

**作用在其中一個量子位元上的閘**
如果只想對第一個量子位元做 H 閘、第二個不動，整體的矩陣就是 H ⊗ I（I 是「什麼都不做」的單位矩陣）。這是 4×4 的矩陣。n 個量子位元的系統，量子閘就是 2ⁿ × 2ⁿ 的矩陣。

**關於順序的小提醒**
不同的工具，對「哪個量子位元寫在左邊」有不同的慣例。例如 Qiskit 把第 0 個量子位元放在**最右邊**，所以 Qiskit 輸出的 `01` 可能代表「第 0 個量子位元是 1」。這是初學者最常踩到的坑之一，用 Qiskit 驗證手算結果時，一定要先確認它的排列順序。

@section CNOT 閘：有條件的翻轉
**CNOT 的規則**
**CNOT 閘**（Controlled-NOT，受控反閘）作用在兩個量子位元上，一個叫**控制位元**，一個叫**目標位元**。規則很簡單：
- 控制位元是 0：目標位元不變；
- 控制位元是 1：目標位元翻轉（做一次 X）。

寫成表格的形式（控制位元在前）：
- |00⟩ → |00⟩
- |01⟩ → |01⟩
- |10⟩ → |11⟩
- |11⟩ → |10⟩

**和一般電腦有什麼不同？**
如果輸入只是 0 和 1，CNOT 就是一個普通的邏輯運算：目標位元變成「控制 XOR 目標」。神奇的地方在於，當控制位元處在**疊加**狀態時會發生什麼事。這就是下一節的主題。

**CNOT 是萬能的關鍵**
一個重要的理論結果：**單量子位元閘加上 CNOT 閘**，就足以組合出**任何**多量子位元的量子操作（可以任意精確地逼近）。這叫做**通用量子閘組**（universal gate set）。所以量子電腦的硬體，只要能做好各種單量子位元旋轉和一種雙量子位元閘，理論上就能執行任何量子演算法。

實際的硬體常常不是直接做 CNOT，而是做其他的雙量子位元閘（例如 CZ 閘），再透過單量子位元閘轉換。但原理是一樣的。雙量子位元閘的錯誤率，通常是一台量子電腦最重要的效能指標之一，因為它比單量子位元閘難做得多。

@section 製造糾纏：貝爾態
**兩個步驟**
從 |00⟩ 開始，只要兩步，就能製造糾纏：
1. 對第一個量子位元做 **H 閘**：狀態變成 (|00⟩ + |10⟩)/√2；
2. 以第一個量子位元為控制、第二個為目標做 **CNOT**：|00⟩ 不變，|10⟩ 變成 |11⟩。

結果是：
|Φ⁺⟩ = (|00⟩ + |11⟩)/√2

這就是最有名的糾纏狀態，叫做**貝爾態**（Bell state），以物理學家約翰·貝爾命名。

**這個狀態有什麼特別？**
測量時：
- 一半的機率得到 00；
- 一半的機率得到 11；
- **永遠不會**得到 01 或 10。

也就是說，每個量子位元單獨看都是完全隨機的（0 和 1 各一半），但**兩者的結果一定相同**。測到第一個是 0，第二個就一定是 0；測到第一個是 1，第二個就一定是 1。

**為什麼說它「糾纏」？**
關鍵在於：**這個狀態無法拆成兩個獨立量子位元的張量積**。你可以試著找 (α₁, β₁) 和 (α₂, β₂)，讓它們的張量積等於 (1/√2, 0, 0, 1/√2)。你會發現：要讓 |01⟩ 的機率幅 α₁β₂ = 0，α₁ 或 β₂ 必須是 0；但這樣一來，|00⟩ 的 α₁α₂ 或 |11⟩ 的 β₁β₂ 就也會有一個是 0，和目標矛盾。

**無法拆開**，就是糾纏的數學定義。兩個量子位元不再各自擁有自己的狀態，只有「整體」才有確定的狀態。

**四個貝爾態**
貝爾態一共有四個，它們組成兩個量子位元的一組完整「基底」：
- |Φ⁺⟩ = (|00⟩ + |11⟩)/√2
- |Φ⁻⟩ = (|00⟩ − |11⟩)/√2
- |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2
- |Ψ⁻⟩ = (|01⟩ − |10⟩)/√2

下一課的量子隱形傳態，就會用到這四個狀態。

@section 糾纏的常見誤解
糾纏是最容易被誤解的量子現象，以下是幾個常見的錯誤說法。

**誤解一：「糾纏可以用來超光速通訊」**
這是最常見的誤解。雖然測量一個量子位元會「立刻」決定另一個的結果，但**你無法控制自己會測到什麼**，結果是隨機的。遠方的人只看到自己這邊隨機的 0 和 1，除非他用一般的通訊方式（電話、網路）知道你的測量結果，否則無法從中得到任何資訊。所以糾纏**不能**用來傳送訊息，也不違反相對論。

**誤解二：「糾纏就是兩個粒子事先講好答案」**
這是愛因斯坦傾向的解釋：兩個粒子在分開前就「約定」好了結果，就像把一雙手套分別裝進兩個盒子，打開一個看到左手，就知道另一個是右手。貝爾在 1964 年證明，**任何「事先約定」的理論，在某些測量組合下的統計結果，都必須滿足一個不等式**（貝爾不等式）。而量子力學預測，糾纏的粒子會**違反**這個不等式。後來的實驗證實了量子力學的預測，這也是 2022 年諾貝爾物理學獎的主題。

**誤解三：「糾纏越多越好」**
糾纏是量子計算的必要資源，但**不是充分條件**。有些電路產生了大量的糾纏，卻仍然可以被一般電腦有效率地模擬。量子演算法的威力，來自糾纏、干涉和精心設計的演算法結構的**組合**。

@section 不可複製定理：量子狀態無法拷貝
**定理的內容**
**不可複製定理**（No-cloning theorem）說：**不存在任何量子操作，能把一個未知的量子狀態完美地複製一份**。

在一般電腦上，複製一個位元再簡單不過了。但在量子世界裡，你不能把一個未知的 α|0⟩ + β|1⟩ 變成兩份一模一樣的 α|0⟩ + β|1⟩。

**為什麼？一個簡短的論證**
假設存在一個複製機 U，能做到：
- U(|0⟩ ⊗ |空白⟩) = |0⟩ ⊗ |0⟩
- U(|1⟩ ⊗ |空白⟩) = |1⟩ ⊗ |1⟩

因為量子操作是**線性的**（矩陣乘法），作用在疊加狀態上，結果必須是兩個結果的疊加：
U(|+⟩ ⊗ |空白⟩) = (|00⟩ + |11⟩)/√2

但我們想要的複製結果是 |+⟩ ⊗ |+⟩ = (|00⟩ + |01⟩ + |10⟩ + |11⟩)/2。兩者不一樣！而且你應該認出來了，實際得到的是上一節的**貝爾態**。所以，線性的量子操作不可能完美複製任意狀態。

**這個定理的影響**
- **量子錯誤更正變得很困難**：一般電腦常用的備份方法是「多複製幾份」，量子電腦不能這樣做。第 96 課會看到，量子錯誤更正用了巧妙得多的方法；
- **量子密碼學的基礎**：竊聽者無法複製傳輸中的量子狀態來偷看，這是第 102 課量子金鑰分發的安全性來源之一；
- **量子程式不能隨意「印出中間結果」**：測量會改變狀態，也不能複製一份來看。這讓量子程式的除錯比一般程式困難得多。

@section 和 AI 一起做：用 AI 驗證你的直覺
多量子位元的狀態很快就會變得難以手算：3 個量子位元就有 8 個機率幅，矩陣是 8×8。這時候「請 AI 解釋 + 自己用程式驗證」的合作方式更加重要。

**請 AI 一步一步推演電路**
```
請一步一步計算以下兩量子位元電路的狀態向量，初始狀態是 |00⟩：
1. 對第 1 個量子位元做 H
2. 以第 1 個為控制、第 2 個為目標做 CNOT
3. 對第 1 個量子位元做 Z
每一步都寫出完整的 4 個機率幅。
最後告訴我結果是哪一個貝爾態。
請使用「第 1 個量子位元寫在左邊」的慣例。
```
指定排列慣例很重要，否則 AI 可能混用不同工具的慣例，導致結果看起來不一致。

**用程式驗證**
AI 給出答案後，用本課的範例程式（或 Qiskit 的 `Statevector`）驗證。你應該會得到 |Φ⁻⟩ = (|00⟩ − |11⟩)/√2。

**請 AI 出「判斷是否糾纏」的題目**
給你幾個雙量子位元狀態，判斷哪些可以拆成張量積（沒有糾纏）、哪些不行（有糾纏）。判斷兩個量子位元的純態是否糾纏，有一個簡單的檢查方法：把四個機率幅排成 2×2 矩陣 [[a, b], [c, d]]，如果 ad − bc = 0 就**沒有**糾纏，否則就有。你可以請 AI 解釋這個方法為什麼成立，再用程式批次檢查。

@section 動動腦：判斷看看
**題一**：狀態 (|00⟩ + |01⟩)/√2 有糾纏嗎？
→ 沒有。它等於 |0⟩ ⊗ |+⟩，可以拆成兩個獨立量子位元的張量積。

**題二**：Alice 和 Bob 共享一對 |Φ⁺⟩ 糾纏量子位元。Alice 測到 1，她能用這個結果立刻告訴遠方的 Bob 一個訊息嗎？
→ 不能。Alice 無法控制測量結果，Bob 只看到隨機結果，必須透過一般通訊才能得知關聯；糾纏不能超光速通訊。

**題三**：為什麼量子電腦不能用「多複製幾份」的方法做錯誤更正？
→ 不可複製定理：未知的量子狀態無法被完美複製。

**題四**：從 |00⟩ 製造貝爾態 |Φ⁺⟩ 需要哪兩個步驟？
→ 先對第一個量子位元做 H 閘，再以它為控制、第二個為目標做 CNOT。

**題五**：一台量子電腦只能做單量子位元旋轉，沒有任何雙量子位元閘，能執行任意量子演算法嗎？
→ 不能。沒有雙量子位元閘就無法產生糾纏；通用量子閘組需要單量子位元閘加上一種能產生糾纏的雙量子位元閘（例如 CNOT）。

@section 本課重點整理
- **張量積**：組合獨立量子位元的方法，各機率幅相乘；NumPy 用 `np.kron`。
- **CNOT 閘**：控制位元為 1 時翻轉目標位元；單量子位元閘加 CNOT 組成通用量子閘組。
- **貝爾態**：H 閘加 CNOT 製造的糾纏狀態，兩個量子位元各自隨機但結果完全相關。
- **糾纏的定義**：整體狀態無法拆成各量子位元狀態的張量積。
- **常見誤解**：糾纏不能超光速通訊；不是事先約定（貝爾不等式被實驗違反）；糾纏是必要但不充分的資源。
- **不可複製定理**：未知量子狀態無法完美複製，影響錯誤更正、密碼學與除錯。
- **注意工具的位元順序慣例**，例如 Qiskit 把第 0 個量子位元放在最右邊。

@term 張量積
組合多個量子系統狀態的運算（Tensor Product，⊗），各機率幅兩兩相乘。
@term CNOT 閘
受控反閘（Controlled-NOT），控制位元為 1 時翻轉目標位元。
@term 通用量子閘組
能組合（逼近）出任意量子操作的一組量子閘，例如單量子位元閘加 CNOT（Universal Gate Set）。
@term 糾纏
多個量子位元的整體狀態無法拆成各自狀態之張量積的現象（Entanglement）。
@term 貝爾態
兩個量子位元最大糾纏的四個狀態，如 (|00⟩ + |11⟩)/√2（Bell States）。
@term 貝爾不等式
任何「事先約定結果」的理論必須滿足、而量子糾纏會違反的統計不等式（Bell Inequality）。
@term 不可複製定理
不存在能完美複製任意未知量子狀態的量子操作（No-Cloning Theorem）。
