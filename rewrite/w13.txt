@section 開場：為什麼我的版面總是亂掉
上一課寫好了語意清楚的 HTML，但它看起來很陽春：所有東西由上往下排成一長條，沒有間距，沒有欄位。這一課用 **CSS** 讓它變得好看、好讀，而且**在手機上也正常**。

很多工程師一碰到 CSS 就焦慮，常見的困惑有：
- 兩個寬度 `50%` 的區塊加了 `padding`，為什麼沒有並排，反而一個掉到下一行？
- 在大螢幕上好好的三欄卡片，用手機打開就出現**左右搖晃的水平捲軸**，字小到按不到按鈕？
- 用 `position: absolute; top: 320px;` 把元素「釘」在某個位置，結果 AI 生成的回答一長，文字就和按鈕**疊在一起**？

我們不需要成為視覺設計師，但要掌握三個「夠用而且穩健」的基本功：
1. **盒模型**：每個元素都是一個盒子，以及寬度到底怎麼算；
2. **Flexbox 和 Grid**：現代排版的兩大工具；
3. **響應式設計**：同一個網頁，在手機、平板、電腦都好看。

以及一個無障礙的重點：**不要把鍵盤焦點框拔掉。**

@section CSS 是什麼：選擇器和規則
**CSS**（Cascading Style Sheets，階層式樣式表）描述 HTML 元素**長什麼樣子**。
```
.card {
  padding: 16px;
  border: 1px solid #ccc;
  border-radius: 8px;
}
```
- `.card`：**選擇器**，選中所有 `class="card"` 的元素；
- 大括號裡是**規則**：內距 16 像素、1 像素的灰色邊框、圓角 8 像素。

常見的選擇器：
- `p`：所有 `<p>` 段落；
- `.card`：所有 class 是 card 的元素；
- `#form-status`：id 是 form-status 的元素；
- `.card h2`：card 裡面的 h2。

「**Cascading**」（層疊）的意思是：多條規則可能同時套用在同一個元素上，瀏覽器依照「越具體的選擇器越優先、後寫的蓋掉先寫的」等規則決定最終樣式。初學時只要記住：**樣式出乎意料時，打開瀏覽器開發者工具（F12），選取元素，就能看到哪些規則生效、哪些被蓋掉。**

@section 盒模型：每個元素都是一個盒子
CSS 排版的第一條物理定律：**頁面上每個元素都是一個矩形盒子**。由內往外有四層：
1. **content（內容）**：文字或圖片本身；
2. **padding（內距）**：內容和邊框之間的空間，會**顯示元素的背景色**；
3. **border（邊框）**：邊框線；
4. **margin（外距）**：盒子和其他盒子之間的**透明**距離，用來推開鄰居。

**比喻：**一幅裱框的畫。畫本身是 content；畫和畫框之間的白色襯紙是 padding；畫框是 border；這幅畫和牆上隔壁那幅畫之間的距離是 margin。

**寬度之謎：為什麼 300 變成 344？**
```
.box {
  width: 300px;
  padding: 20px;
  border: 2px solid black;
}
```
這個盒子在畫面上實際占了 **344 像素**寬！

因為 CSS 的歷史預設值 `box-sizing: content-box`，把 `width` 定義為「**只有最內層 content 的寬度**」。加上左右 padding 各 20、左右 border 各 2：
$300 + 20 \times 2 + 2 \times 2 = 344$

這就解釋了開場的謎題：兩個 `50%` 寬的區塊加了 padding 後，加起來超過 100%，第二個只好擠到下一行。

**解法：現代 CSS 的第一行起手式。**
```
*, *::before, *::after {
  box-sizing: border-box;
}
```
改成 `border-box` 後，`width: 300px` 就代表「**content + padding + border 總共 300**」。你設多寬就是多寬，瀏覽器會自動把內容區縮小來容納 padding 和邊框。

**注意：margin 永遠在盒子外面，不算在 width 裡。**

**比喻：**`content-box` 像訂畫框時只告訴店家「畫是 30 公分」，結果加上襯紙和框變成 34 公分，掛不進預留的位置；`border-box` 是告訴店家「整個裱好的成品要 30 公分」，店家會自己調整襯紙的寬度。

@section 三種排版方式：正常流、Flexbox、Grid
要排列很多個盒子時，有三種主要工具。

**一、正常文件流（Normal Flow）：預設就是它。**
不做任何設定時，區塊元素（`<p>`、`<section>`、`<h2>`）由上往下一個疊一個，像文章一樣。**大部分內容用正常流就夠了。**它最大的優點是：內容變長時，下面的東西會**自動往下推**，永遠不會重疊。

**二、Flexbox：一維排列（一條線上排東西）。**
適合「**一排**」或「**一列**」的東西：導覽列、按鈕群組、標籤和輸入框對齊。
```
.site-nav {
  display: flex;
  justify-content: space-between;  /* 主軸方向：兩端對齊 */
  align-items: center;             /* 交叉方向：垂直置中 */
  flex-wrap: wrap;                 /* 空間不夠時換行 */
  gap: 12px;                       /* 項目之間的間距 */
}
```
效果：Logo 在最左邊、選單連結在最右邊，垂直置中；螢幕太窄時自動換行，不會擠爆。

**比喻：**Flexbox 像在一根晾衣繩上掛衣服。你可以決定衣服靠左、靠右、平均分散，繩子不夠長時再拉第二條繩子（換行）。

**三、Grid：二維排列（列和欄的表格式配置）。**
適合「**網格**」狀的東西：卡片牆、儀表板、相簿。
```
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}
```
- `repeat(3, ...)`：三欄；
- `1fr`：`fr` 是「**剩餘空間的一份**」（fraction）。三欄各 `1fr` 就是平分；
- `gap: 16px`：格子之間的間距。

**比喻：**Grid 像一個有格子的收納櫃。先決定幾欄、每欄多寬，東西放進去就自動對齊。

**一個重要的小技巧：為什麼寫 `minmax(0, 1fr)` 而不是 `1fr`？**
只寫 `1fr` 時，每一欄的**最小寬度**預設是「內容的最小寬度」。如果某張卡片裡有一行很長的英文網址或程式碼（沒有空白、無法斷行），這一欄就會被**硬撐開**，整個版面爆出螢幕。

寫成 `minmax(0, 1fr)`，意思是「最小可以縮到 0，最大是一份」。欄位寬度就會守規矩，過長的內容再另外處理（下面會講）。

**選擇原則：**
- 內容由上往下排 → 正常流；
- 一條線上排列、對齊 → Flexbox；
- 列和欄都要對齊的網格 → Grid。

@section 不要用 absolute 排主要版面
`position: absolute` 會讓元素**脫離正常文件流**：它被「拔起來」釘在指定座標上，周圍的元素會當它**不存在**，直接佔用它原本的位置。

所以當上方的內容變長（例如 AI 回答多了幾行），被釘住的元素不會跟著往下移，兩者就**疊在一起**了。

**比喻：**正常流像排隊，前面的人變多，後面的人自然往後退；absolute 像用釘子把一個人釘在地板上某一格，不管隊伍怎麼變，他都不動，最後就和別人撞在一起。

absolute 適合的是**小範圍的裝飾**，例如卡片右上角的「新」字小標籤。**主要版面一律交給正常流、Flexbox 和 Grid**，讓高度隨內容自然撐開。

@section 響應式設計：一個網頁適應所有螢幕
使用者可能用 375 像素寬的手機、768 像素的平板、1280 像素的筆電，甚至 4K 大螢幕。**響應式設計**（Responsive Design）就是讓同一份網頁，在不同寬度下自動調整版面。

**工具：媒體查詢（Media Query）。**
```
.cards {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}

@media (max-width: 900px) {
  .cards { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}

@media (max-width: 640px) {
  .cards { grid-template-columns: 1fr; }
}
```
意思是：
- 預設三欄；
- 螢幕寬度 900 像素以下，改兩欄；
- 640 像素以下（手機），改一欄。

這些切換點叫做「**斷點**」（Breakpoint）。

**比喻：**像一張可以變形的餐桌。客人多時拉開成長桌（三欄），客人少時收成方桌（一欄），不管幾個人來都坐得舒服。

**限制最大寬度：別讓文字拉成一長條。**
```
main {
  max-width: 1120px;
  margin: 0 auto;   /* 左右自動置中 */
  padding: 16px;    /* 手機上左右留白 */
}
```
在超寬螢幕上，如果文字橫跨整個畫面，一行可能有 200 個字，讀完一行要轉頭找下一行的開頭，非常累。人類舒適的閱讀行寬大約是 60 到 75 個字元。`max-width` 讓內容在大螢幕上置中、保持適當寬度。

**長程式碼：只讓它自己捲動。**
```
pre {
  overflow-x: auto;
  max-width: 100%;
}
```
很長的程式碼區塊，只在**自己的盒子裡**左右捲動，而不是讓整個網頁出現水平捲軸。

**驗收方法：**用瀏覽器開發者工具的「裝置模擬」功能，分別在 375、768、1280 像素寬度下檢查：**整頁不應出現水平捲軸**，按鈕要夠大、文字要看得清楚。

@section 無障礙：不要拔掉焦點框
用鍵盤 Tab 操作時，目前聚焦的元素外面會有一圈**焦點框**（outline）。有些人覺得它醜，就寫：
```
*:focus { outline: none; }   /* 千萬不要！ */
```
這對鍵盤使用者來說，等於**把滑鼠游標藏起來**：他完全不知道現在按 Enter 會觸發哪個按鈕。

**正確做法：用 `:focus-visible`。**
```
:focus-visible {
  outline: 3px solid #315dff;
  outline-offset: 3px;
}
```
`:focus-visible` 很聰明：用**滑鼠點擊**時不顯示（不影響美觀），用**鍵盤操作**時才顯示清楚的焦點框。兩全其美。

**其他無障礙提醒：**
- **不要只靠顏色傳達資訊**：紅色代表錯誤、綠色代表成功，但色覺辨識障礙的人可能分不出來。要搭配文字或圖示，例如「✓ 已通過」、「✕ 欄位錯誤」；
- **不要寫死高度**：`height: 200px` 的容器，使用者把字體放大到 150%，文字就會溢出切邊。改用 `min-height`（最少多高，內容多時可以長高）；
- **輸入框寬度**：設 `width: 100%; max-width: 100%;`，避免在手機上撐破父容器。

@section 走一遍：替學生管理頁面加上樣式
把第 55 課的頁面套上樣式：

**第一步：全域設定。**`box-sizing: border-box`；`main` 設 `max-width` 並置中。

**第二步：導覽列用 Flexbox。**`display: flex; justify-content: space-between; align-items: center; flex-wrap: wrap; gap: 12px;`。

**第三步：課程卡片用 Grid。**三欄 `repeat(3, minmax(0, 1fr))`；900 像素以下兩欄、640 像素以下一欄。

**第四步：處理細節。**`pre` 加 `overflow-x: auto`；`:focus-visible` 設定清楚的焦點框；錯誤訊息除了紅色還加上「✕」。

**第五步：三種寬度驗收。**375、768、1280 像素下都不出現水平捲軸；用鍵盤 Tab 一遍，每個焦點都看得見。

@section 動動腦：判斷看看
**題一**：預設 `content-box` 下，`width: 300px; padding: 20px; border: 2px` 實際多寬？改成 `border-box` 呢？
→ 344 像素；改成 `border-box` 後是 300 像素（margin 仍另外算）。

**題二**：導覽列要 Logo 靠左、連結靠右，該用 Flexbox 還是 Grid？卡片牆呢？
→ 導覽列是一維排列，用 Flexbox；卡片牆是二維網格，用 Grid。

**題三**：某張卡片裡有一行超長網址，把三欄版面撐爆了，怎麼修？
→ 欄位改用 `minmax(0, 1fr)`，並讓長內容換行或在自己的盒子裡 `overflow-x: auto`。

**題四**：設計師覺得焦點框很醜，要求全部拿掉，該怎麼回應？
→ 改用 `:focus-visible`：滑鼠點擊時不顯示，鍵盤操作時才顯示，兼顧美觀與無障礙。

@section 本課重點整理
- **CSS**：用選擇器選中元素、用規則描述外觀；樣式出問題時用 F12 開發者工具檢查。
- **盒模型**：content → padding → border → margin。
- **`box-sizing: border-box`**：讓 width 包含 padding 與 border，是現代 CSS 的起手式；margin 不算在內。
- **三種排版**：正常流（預設、內容自然往下推）、Flexbox（一維）、Grid（二維）。
- **`minmax(0, 1fr)`**：防止超長內容撐爆 Grid 欄位。
- **不要用 absolute 排主要版面**：它脫離文件流，內容一變長就重疊。
- **響應式設計**：媒體查詢設定斷點；`max-width` 控制行寬；長程式碼只在自己的盒子捲動。
- **無障礙**：用 `:focus-visible` 而不是拔掉焦點框；不只靠顏色傳達資訊；避免寫死高度。

@term CSS
描述網頁元素外觀與排版的樣式語言（Cascading Style Sheets）。
@term 選擇器
CSS 中用來選中要套用樣式之元素的語法，例如 .card、#id（Selector）。
@term 盒模型
每個元素由內容、內距、邊框、外距四層構成的矩形模型（Box Model）。
@term padding
內距，內容與邊框之間的空間，會顯示背景色。
@term margin
外距，盒子與其他盒子之間的透明距離。
@term border-box
讓 width 包含內容、內距與邊框的 box-sizing 設定。
@term 正常文件流
元素預設由上往下依序排列、內容變長時自動往下推的排版方式（Normal Flow）。
@term Flexbox
沿單一方向排列與對齊元素的一維排版工具。
@term Grid
同時控制列與欄的二維排版工具。
@term fr
Grid 中代表「剩餘空間一份」的單位（fraction）。
@term 響應式設計
讓同一網頁在不同螢幕寬度下自動調整版面的設計方式（Responsive Design）。
@term 媒體查詢
依螢幕寬度等條件套用不同樣式的 CSS 語法（Media Query）。
@term 斷點
響應式設計中切換版面的螢幕寬度（Breakpoint）。
@term focus-visible
只在鍵盤操作時顯示焦點框的 CSS 選擇器。
