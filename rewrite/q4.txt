@section 開場：測量不是「看一眼」而已
在一般電腦上，讀取一個變數不會改變它的值，你可以想讀幾次就讀幾次。量子電腦完全不同：**測量本身就是一個會改變系統的操作**。測量之後，疊加狀態會「塌縮」成其中一個結果，原本的機率幅資訊就消失了。

這一課要更仔細地認識測量，然後用前三課學到的工具，完成一個經典的量子協定：**量子隱形傳態**（quantum teleportation）。最後，我們會介紹真實量子電腦一定要面對的概念：**混合態**與**密度矩陣**，它是理解雜訊（第 95 課）和錯誤更正（第 96 課）的基礎。

這一課的內容：
- 測量的規則：機率、塌縮、部分測量；
- 在不同基底測量；
- 量子隱形傳態：傳送的到底是什麼？
- 純態與混合態、密度矩陣；
- 去相干：量子性為什麼這麼脆弱。

@section 測量的規則
**波恩規則**
第 87 課已經用過這條規則：測量狀態 α|0⟩ + β|1⟩，得到 0 的機率是 |α|²，得到 1 的機率是 |β|²。這叫做**波恩規則**（Born rule）。

**塌縮**
測量之後，狀態就**變成**你測到的那個結果。測到 0，狀態就變成 |0⟩；如果立刻再測一次，一定還是 0。原本的 α 和 β 不見了，無法再找回來。

**一次測量只得到一個位元**
這是理解量子計算限制的關鍵。n 個量子位元的狀態有 2ⁿ 個機率幅，但**一次測量只能得到 n 個位元的結果**。所以「量子電腦同時計算所有可能，再把所有答案讀出來」是錯誤的說法。量子演算法真正的技巧，是透過**干涉**，讓正確答案的機率幅變大、錯誤答案的機率幅互相抵消，這樣測量時才更可能得到正確答案。

**要多次執行才能估計機率**
因為每次測量只得到一個隨機結果，實務上要把同一個電路執行很多次（每一次叫一個 **shot**），統計各結果出現的次數。例如執行 1000 次，得到 0 有 503 次、1 有 497 次，就能估計機率大約各一半。shot 數越多，估計越準，但誤差只會隨 shot 數的平方根縮小：shot 數變成 4 倍，誤差才減半。這在第 98 課的變分演算法裡，會變成實際的成本問題。

**部分測量**
如果只測量兩個量子位元中的一個呢？以貝爾態 (|00⟩ + |11⟩)/√2 為例：
- 測量第一個量子位元，一半機率得到 0，此時整體狀態變成 |00⟩；
- 一半機率得到 1，此時整體狀態變成 |11⟩。

規則是：保留和測量結果**一致**的那些項，然後重新**正規化**（讓機率總和回到 1）。例如狀態 (|00⟩ + |01⟩ + |10⟩)/√3，測量第一個量子位元得到 0 的機率是 2/3，之後的狀態是 (|00⟩ + |01⟩)/√2。

@section 在不同基底測量
**基底是什麼？**
到目前為止，我們都是在 |0⟩、|1⟩ 這組基底（叫做**計算基底**或 Z 基底）測量。但也可以在其他基底測量，例如 |+⟩、|−⟩ 這組（叫 X 基底）。

**怎麼做？先轉換，再測量**
量子硬體通常只能在計算基底測量。想在 X 基底測量，方法是：**先做一個 H 閘，再測量**。因為 H 會把 |+⟩ 變成 |0⟩、|−⟩ 變成 |1⟩，所以測到 0 就代表原本是 |+⟩、測到 1 就代表原本是 |−⟩。

**同一個狀態，不同基底，結果完全不同**
- |0⟩ 在 Z 基底測量：100% 得到 0；
- |0⟩ 在 X 基底測量：50% 得到 +，50% 得到 −。

一個狀態在某個基底下很「確定」，在另一個基底下可能完全「隨機」。這種特性，正是第 102 課 BB84 量子金鑰分發的核心：竊聽者不知道該用哪個基底測量，猜錯基底就會擾亂狀態，被通訊雙方發現。

**期望值**
在 AI 結合量子的應用裡（第 98、99 課），我們常常不是要某個特定的測量結果，而是要一個**平均值**，叫做**期望值**（expectation value）。例如 Z 的期望值定義為：
⟨Z⟩ = P(0) × (+1) + P(1) × (−1)

|0⟩ 的 ⟨Z⟩ 是 +1，|1⟩ 是 −1，|+⟩ 是 0。變分量子演算法和量子機器學習模型，通常就是把這種期望值當作模型的「輸出」。

@section 量子隱形傳態：傳送的到底是什麼？
**問題情境**
Alice 手上有一個未知的量子狀態 |ψ⟩ = α|0⟩ + β|1⟩，她想把這個狀態傳給遠方的 Bob。困難在於：
- 她不能直接測量 |ψ⟩ 來得知 α 和 β，因為測量會讓狀態塌縮，而且只得到一個位元；
- 她也不能複製一份（第 89 課的不可複製定理）；
- 假設她無法直接把量子位元送過去。

**解法：糾纏 + 兩個古典位元**
1. **事先準備**：Alice 和 Bob 各持有一個貝爾態 |Φ⁺⟩ 的量子位元；
2. **Alice 操作**：Alice 把 |ψ⟩ 和她那一半的糾纏量子位元做 CNOT，再對 |ψ⟩ 做 H 閘；
3. **Alice 測量**：她測量自己的兩個量子位元，得到兩個古典位元（00、01、10 或 11 其中之一）；
4. **傳送古典訊息**：她用一般的方式（電話、網路）把這兩個位元告訴 Bob；
5. **Bob 修正**：根據這兩個位元，Bob 對自己的量子位元做對應的修正：
   - 00：不做事；
   - 01：做 X；
   - 10：做 Z；
   - 11：先做 X 再做 Z。

完成後，Bob 的量子位元就**變成** α|0⟩ + β|1⟩。

**常見誤解的釐清**
- **沒有傳送物質**：被「傳送」的是量子**狀態**（資訊），不是粒子本身；
- **不違反不可複製定理**：Alice 測量後，她手上的原始狀態就被破壞了。整個過程結束時，世界上仍然只有一份 |ψ⟩；
- **不能超光速**：Bob 在收到 Alice 的兩個古典位元之前，他的量子位元看起來完全是隨機的，無法得到任何資訊。古典通訊受光速限制，所以隱形傳態也是；
- **Alice 和 Bob 都不知道 α 和 β 是多少**：狀態被完整轉移了，但沒有人「讀」到它。

**為什麼重要？**
隱形傳態不只是一個酷炫的展示：它是**量子網路**和**分散式量子計算**的基本元件，也被用在一些錯誤更正方案和量子閘的實作方法裡。2017 年中國的墨子號衛星，就完成了地面與衛星之間超過一千公里的量子隱形傳態實驗。

@section 純態與混合態：密度矩陣
**兩種不同的「不確定」**
考慮兩種情況：
- **情況 A**：一個量子位元處在 |+⟩ = (|0⟩ + |1⟩)/√2；
- **情況 B**：一台機器隨機丟硬幣，一半時候給你 |0⟩，一半時候給你 |1⟩，但不告訴你是哪一個。

在 Z 基底測量，兩種情況都是 50% 得到 0、50% 得到 1，看起來一樣。但在 **X 基底**測量：
- 情況 A：100% 得到 +；
- 情況 B：50% 得到 +，50% 得到 −。

兩者是不同的！情況 A 是**量子疊加**，0 和 1 之間有確定的相位關係，可以干涉；情況 B 只是我們**不知道**是哪一個，是古典的不確定性，沒有干涉能力。

情況 A 叫做**純態**（pure state），情況 B 叫做**混合態**（mixed state）。

**密度矩陣**
狀態向量只能描述純態。為了同時描述兩種不確定性，物理學家使用**密度矩陣**（density matrix），通常寫作 ρ（念作 rho）。對於純態 |ψ⟩，ρ = |ψ⟩⟨ψ|（向量乘以它自己的共軛轉置，得到一個矩陣）。對於混合態，就是各個純態的密度矩陣按機率加權平均。

以單一量子位元為例：
- |+⟩ 的密度矩陣：[[0.5, 0.5], [0.5, 0.5]]
- 情況 B（一半 |0⟩ 一半 |1⟩）：[[0.5, 0], [0, 0.5]]

對角線上的數字是測量 0 和 1 的機率，兩者相同；**非對角線**的數字（叫做**相干項**，coherence）代表量子疊加的「干涉能力」。情況 B 的相干項是 0，所以它沒有量子干涉的能力。

**純度**
有一個簡單的指標可以判斷純態還是混合態：**純度** = ρ² 的跡（對角線總和）。純態的純度是 1；單一量子位元最混合的狀態，純度是 0.5。

**在布洛赫球上的位置**
第 88 課說純態都在布洛赫球的**表面**上。混合態則在球的**內部**，越接近球心越混合；正中心就是「完全隨機」的狀態。

**糾纏與混合態的關係**
如果你只看貝爾態 (|00⟩ + |11⟩)/√2 的**其中一個**量子位元，忽略另一個，它的狀態會是 [[0.5, 0], [0, 0.5]]，也就是最混合的狀態。整體是純態，局部卻是完全混合，這正是糾纏的另一個標誌。

@section 去相干：量子性為什麼這麼脆弱
**環境偷偷「測量」了你的量子位元**
真實的量子位元並不是孤立的。它會和周圍環境（電磁場、溫度、材料缺陷）產生微弱的交互作用。這些交互作用就像是環境在偷偷地測量量子位元，或者讓量子位元和環境產生糾纏。結果就是：從我們的角度看，量子位元的**相干項逐漸消失**，純態慢慢變成混合態。這個過程叫做**去相干**（decoherence）。

**兩個時間常數**
量子硬體的規格表常常列出兩個數字：
- **T1**（能量弛豫時間）：量子位元從 |1⟩ 自發地掉回 |0⟩ 的特徵時間，就像高處的球會滾下來；
- **T2**（去相位時間）：相干項衰減的特徵時間，也就是疊加的相位資訊被「洗掉」的速度。

對超導量子位元來說，這些時間通常在幾十到幾百微秒的範圍（不同晶片差異很大）；離子阱和中性原子平台可以長得多，但閘操作也比較慢。真正重要的指標，是**在相干時間內能做多少次可靠的閘操作**。

**這就是為什麼量子電腦這麼難造**
量子計算需要：
- 量子位元和外界**隔離**，才能保持相干；
- 又要能**精準控制**和**測量**，就必須和外界連接。

這兩個需求互相矛盾，是量子硬體工程最根本的挑戰。第 95 課會討論雜訊的種類，第 96 課則介紹解決方法：量子錯誤更正。

@section 和 AI 一起做：讓 AI 當你的協定助教
隱形傳態是一個多步驟的協定，非常適合讓 AI 陪你「逐步追蹤」，但也很容易在細節出錯（例如修正步驟的順序、位元順序慣例）。

**請 AI 逐步追蹤三個量子位元的狀態**
```
請追蹤量子隱形傳態協定，初始狀態是 |ψ⟩ ⊗ |Φ⁺⟩，其中 |ψ⟩ = α|0⟩ + β|1⟩。
量子位元順序：q0 = |ψ⟩，q1 = Alice 的糾纏半邊，q2 = Bob 的。
步驟：CNOT(q0→q1)、H(q0)、測量 q0 和 q1。
請寫出測量前的完整狀態，並把它整理成
「(q0q1 的四種結果) ⊗ (Bob 對應的狀態)」的形式。
```
整理成這種形式後，你就能直接看出每種測量結果下 Bob 需要哪種修正。

**用程式驗證**
請 AI 寫一段純 NumPy 的模擬，隨機產生 α 和 β，跑完協定後，比對 Bob 的狀態和原始狀態的**保真度**（兩個狀態內積的絕對值平方，1 代表完全相同）。驗證四種測量結果下，保真度都是 1。

**用 AI 釐清觀念，但要追問**
可以問 AI：「隱形傳態為什麼不違反相對論？」好的回答應該提到「Bob 在收到古典位元之前，他的量子位元的密度矩陣是完全混合的」。如果 AI 只回答「因為需要古典通訊」而沒有解釋原因，就再追問：「請用 Bob 那一個量子位元的密度矩陣說明。」這樣的追問能讓你學得更紮實。

@section 動動腦：判斷看看
**題一**：狀態 (|00⟩ + |01⟩ + |10⟩)/√3，測量第一個量子位元得到 1 之後，狀態是什麼？
→ |10⟩。只保留第一個量子位元是 1 的項，正規化後就是 |10⟩。

**題二**：想在 X 基底（|+⟩、|−⟩）測量一個量子位元，硬體只支援計算基底測量，該怎麼做？
→ 先做 H 閘，再在計算基底測量。

**題三**：|+⟩ 和「一半機率 |0⟩、一半機率 |1⟩」的混合態，用什麼方法能區分？
→ 在 X 基底測量：|+⟩ 永遠得到 +，混合態則一半一半。在密度矩陣上，差別在於非對角線的相干項。

**題四**：量子隱形傳態中，Alice 需要傳給 Bob 什麼？
→ 兩個古典位元（她的測量結果）。量子狀態本身是透過事先共享的糾纏加上這兩個位元重建的。

**題五**：一個量子位元的 T2 時間很短，代表什麼？
→ 疊加的相位資訊很快就會被環境洗掉（去相干很快），能在相干時間內完成的可靠閘操作很少。

@section 本課重點整理
- **測量**：依波恩規則隨機得到結果，之後狀態塌縮；n 個量子位元一次只讀出 n 個位元。
- **多次執行（shots）**：用統計估計機率，誤差隨 shot 數平方根縮小。
- **部分測量**：保留一致的項並重新正規化。
- **換基底測量**：先做轉換（例如 H），再測量；同一狀態在不同基底下的結果可能完全不同。
- **期望值**：測量結果的平均，是變分演算法與量子機器學習模型的輸出。
- **量子隱形傳態**：用糾纏加兩個古典位元傳送量子狀態；不傳物質、不複製、不超光速。
- **混合態與密度矩陣**：描述古典的不確定性；相干項代表干涉能力；純度為 1 是純態。
- **去相干**：環境讓相干項消失，T1、T2 是關鍵指標；隔離與控制的矛盾是硬體的根本難題。

@term 波恩規則
量子測量得到某結果的機率等於該結果機率幅的絕對值平方（Born Rule）。
@term 塌縮
測量後量子狀態變成所測到結果對應狀態的現象（Collapse）。
@term shot
量子電路的一次執行與測量；要多次執行才能統計出機率分布。
@term 期望值
測量結果依機率加權的平均值，例如 ⟨Z⟩ = P(0) − P(1)（Expectation Value）。
@term 量子隱形傳態
利用事先共享的糾纏與兩個古典位元，把未知量子狀態轉移到遠端的協定（Quantum Teleportation）。
@term 密度矩陣
能同時描述量子疊加與古典不確定性的矩陣表示法 ρ（Density Matrix）。
@term 混合態
帶有古典不確定性、無法用單一狀態向量描述的量子狀態（Mixed State）。
@term 去相干
量子系統與環境交互作用導致相干性（疊加的相位資訊）流失的過程（Decoherence）。
@term T1 與 T2
量子位元的能量弛豫時間與去相位時間，是衡量相干性的兩個關鍵指標。
