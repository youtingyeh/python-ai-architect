@section 開場：一個量子位元能做多少事？
上一課我們學會了用向量表示量子狀態、用矩陣表示量子閘。這一課要專心研究**單一個量子位元**：它所有可能的狀態長什麼樣子？常用的量子閘有哪些？它們各自做了什麼？

你可能會覺得：只有一個量子位元，能有多複雜？一般電腦的一個位元只有 0 和 1 兩種狀態，能做的操作也只有「不變」和「反轉」兩種。但一個量子位元的狀態有**無限多種**，可以做的操作也有無限多種。這一課會用一個很漂亮的幾何圖像，把這些無限多的可能性變得容易想像：**布洛赫球**（Bloch sphere）。

學會布洛赫球之後，你會發現每一個單量子位元的量子閘，都只是**把球上的點轉一個角度**。這個圖像在 IBM 的 Qiskit 教材和幾乎所有量子計算課程裡都會出現，是建立直覺最重要的工具。

@section 布洛赫球：把狀態畫成球面上的點
**從兩個複數到球面上的一個點**
一個量子位元的狀態是 α|0⟩ + β|1⟩，α 和 β 是複數。兩個複數有四個實數（各自的實部和虛部），看起來需要四維空間才畫得出來。但有兩個條件可以把維度降下來：

1. **歸一化**：|α|² + |β|² = 1，少了一個自由度；
2. **整體相位不重要**：如果把 α 和 β **同時**乘上同一個角度的旋轉，所有測量結果都完全不會改變。物理上，這兩個狀態是同一個狀態。又少了一個自由度。

剩下兩個自由度，剛好可以用**球面上的一個點**表示，就像地球表面上的位置可以用緯度和經度兩個數字描述。

**怎麼讀這顆球？**
- **北極**是 |0⟩，**南極**是 |1⟩；
- **赤道**上的點，是 |0⟩ 和 |1⟩ 一半一半的疊加。其中 |+⟩ 在赤道的「正前方」，|−⟩ 在「正後方」，兩者正好相對；
- **緯度**（離北極多遠）決定測量的機率：越靠近北極，測到 0 的機率越高；
- **經度**（繞著地軸的角度）就是**相對相位**：它不影響測量 0 或 1 的機率，但會影響干涉。

所以，赤道上所有的點，測量時都是 0 和 1 各一半，但它們是**不同的狀態**，就像赤道上的新加坡和厄瓜多爾雖然緯度相同，卻是不同的地方。上一課的 |+⟩ 和 |−⟩ 就是這樣的例子。

**球面上「正好相對」的兩點是正交的**
北極和南極（|0⟩ 和 |1⟩）、赤道上正前方和正後方（|+⟩ 和 |−⟩），都是正好相對的兩點，它們的內積都是 0，可以被完美分辨。注意這裡有一個容易混淆的地方：在一般的向量空間裡，正交是「夾角 90 度」；在布洛赫球上，正交是「夾角 180 度」。

**布洛赫球的限制**
布洛赫球只能畫**一個**量子位元。兩個以上的量子位元，特別是有糾纏的時候，就沒有這麼簡單的圖像了。這也是量子計算的威力所在：多量子位元的狀態空間，遠比任何簡單的幾何圖像更豐富。

@section 泡利閘：繞三個軸轉半圈
最基本的三個量子閘，叫做**泡利閘**（Pauli gates），以物理學家泡利命名。它們分別代表**繞 X 軸、Y 軸、Z 軸旋轉 180 度**。

先定義布洛赫球的三個軸：
- **Z 軸**：連接北極（|0⟩）和南極（|1⟩）的地軸；
- **X 軸**：在赤道上，連接 |+⟩ 和 |−⟩；
- **Y 軸**：在赤道上，和 X 軸垂直。

**X 閘：量子版的 NOT**
```
X = [[0, 1],
     [1, 0]]
```
繞 X 軸轉 180 度，北極會轉到南極，所以 |0⟩ 變成 |1⟩、|1⟩ 變成 |0⟩。這和一般電腦的 NOT 閘效果一樣，所以也叫「**位元翻轉**」（bit flip）。而 |+⟩ 剛好在 X 軸上，繞著自己所在的軸轉，位置不變。

**Z 閘：相位翻轉**
```
Z = [[1,  0],
     [0, -1]]
```
繞 Z 軸轉 180 度，北極和南極都在 Z 軸上，所以 |0⟩ 和 |1⟩ 都不變。但赤道上的點會轉到對面：|+⟩ 變成 |−⟩。

從矩陣來看，Z 閘把 α|0⟩ + β|1⟩ 變成 α|0⟩ − β|1⟩，也就是**把 |1⟩ 那一項的正負號反過來**。這叫「**相位翻轉**」（phase flip）。這是一般電腦完全沒有的操作：測量機率完全不變，但狀態已經不同了。

**Y 閘**
```
Y = [[0, -i],
     [i,  0]]
```
繞 Y 軸轉 180 度。它同時做了位元翻轉和相位翻轉（還多了一個整體相位）。

**為什麼泡利閘很重要？**
除了是基本的量子閘，泡利閘還代表了量子電腦上**最基本的錯誤類型**：雜訊可能讓量子位元意外地做了一次 X（位元翻轉錯誤）或 Z（相位翻轉錯誤）。第 95、96 課談雜訊和錯誤更正時，會一再看到這三個名字。

@section 阿達瑪閘：製造疊加的關鍵
**H 閘**
在所有量子閘中，最常用的大概就是**阿達瑪閘**（Hadamard gate），簡稱 H 閘：
```
H = (1/√2) × [[1,  1],
              [1, -1]]
```
它的效果：
- |0⟩ → |+⟩：從北極轉到赤道；
- |1⟩ → |−⟩：從南極轉到赤道的另一邊；
- |+⟩ → |0⟩、|−⟩ → |1⟩：反過來也一樣。

幾何上，H 閘是繞著「X 軸和 Z 軸的正中間那條斜軸」轉 180 度，所以它把 Z 軸和 X 軸**互換**。

**H 閘的兩個用途**
1. **製造疊加**：幾乎每個量子演算法的第一步，都是對所有量子位元做 H 閘，把它們從確定的 |0⟩ 變成均勻的疊加；
2. **切換「看的方向」**：上一課說 |+⟩ 和 |−⟩ 直接測量分辨不出來。但先做一次 H 閘，|+⟩ 變成 |0⟩、|−⟩ 變成 |1⟩，再測量就能百分之百分辨了。這相當於「**在 X 軸方向測量**」。

**H 閘做兩次，會回到原點**
H × H = 單位矩陣。第 85 課的範例裡已經看過：|0⟩ 經過一次 H 變成一半一半，再經過一次 H，又變回確定的 |0⟩。這就是**干涉**的最簡單例子：第二次 H 讓 |1⟩ 的兩條路徑（一條帶正號、一條帶負號）互相抵消了。

@section 相位閘與旋轉閘：轉任意角度
**S 閘與 T 閘**
泡利閘只能轉 180 度。如果想繞 Z 軸轉比較小的角度，就用相位閘：
- **S 閘**：繞 Z 軸轉 90 度。把 |1⟩ 那一項乘上 i；
- **T 閘**：繞 Z 軸轉 45 度。把 |1⟩ 那一項乘上「角度為 45 度的單位複數」。

T 閘在第 86 課出現過：它是未來容錯量子電腦上**最昂貴的操作之一**，AlphaTensor-Quantum 的目標就是減少它的數量。原因會在第 96 課錯誤更正時說明：大部分的量子閘在錯誤更正後都可以很便宜地執行，但 T 閘需要一個叫做「魔術態」的特殊資源，製造成本很高。

**旋轉閘：連續可調的角度**
更一般的做法，是使用**旋轉閘** RX(θ)、RY(θ)、RZ(θ)，分別代表繞 X、Y、Z 軸轉任意角度 θ。這裡的 θ 是一個可以連續調整的**參數**。

旋轉閘在量子機器學習中特別重要。第 86 課的範例，就是用 RY(θ) 調整角度，讓測到 1 的機率接近目標值。第 98、99 課的變分量子演算法和量子神經網路，本質上就是**很多個旋轉閘的角度一起被訓練**，就像神經網路的權重一樣。

**任何單量子位元閘都能用旋轉組合出來**
一個很重要的數學結果：任何作用在單一量子位元上的量子閘，都可以拆成**三次旋轉**的組合（例如先繞 Z、再繞 Y、再繞 Z）。所以只要能做旋轉閘，就能做出所有的單量子位元操作。這有點像任何顏色都能用紅、綠、藍三原色調出來。

@section 實作：用程式模擬單一量子位元
本課的程式範例，用 NumPy 實作了常用的單量子位元閘，並計算布洛赫球上的座標。建議你動手修改程式，觀察：
- |0⟩ 依序經過 H、Z、H 之後變成什麼？（答案是 |1⟩：H-Z-H 的效果等於 X。這說明了 H 閘「把 Z 軸和 X 軸互換」的性質）
- 對 |0⟩ 做 RY(θ)，θ 從 0 慢慢增加到 180 度，布洛赫球上的點怎麼移動？測到 1 的機率怎麼變化？

**用 Qiskit 做同樣的事**
如果你已經安裝 Qiskit，同樣的電路可以這樣寫：
```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

qc = QuantumCircuit(1)
qc.h(0)
qc.z(0)
qc.h(0)
print(Statevector.from_instruction(qc))  # 結果應該是 |1⟩
```
Qiskit 的 `Statevector` 會直接計算電路結束時的狀態向量，很適合用來檢查你的手算結果。（Qiskit 的版本更新很快，如果語法有變動，請以官方文件為準。）

@section 和 AI 一起做：用 AI 建立幾何直覺
布洛赫球是很視覺化的概念，而文字很難完整描述三維的旋轉。這時可以請 AI 幫你**產生視覺化的程式**，自己執行來看。

**請 AI 寫視覺化程式**
```
請用 Python 的 matplotlib 畫一個布洛赫球（3D），並標示 |0⟩、|1⟩、|+⟩、|−⟩ 的位置。
然後畫出狀態 |0⟩ 經過 RY(θ) 時，θ 從 0 到 π 的移動軌跡。
請只使用 numpy 和 matplotlib，不要使用 qiskit 的內建畫圖功能，
並在程式中加上註解，說明布洛赫座標是怎麼從機率幅計算出來的。
```
最後一個要求很重要：**要求 AI 自己寫出計算過程**，而不是呼叫現成的函式。這樣你讀程式碼的時候，就能同時學到背後的數學。

**用程式檢查 AI 的說法**
AI 可能會說「S 閘做兩次等於 Z 閘」，你可以馬上用 NumPy 驗證：`np.allclose(S @ S, Z)`。這種「AI 提出命題、你用程式驗證」的練習，比單純讀答案有效得多。下面是幾個可以請 AI 出題、再自己驗證的命題：
- H × X × H 是否等於 Z？
- T 閘做幾次會等於 Z 閘？
- 任何泡利閘做兩次，是否都會回到原狀？

**注意整體相位**
驗證時你可能會發現，有些矩陣「差了一個整體相位」，例如結果是 −Z 而不是 Z。上一節說過，整體相位不影響任何測量結果，物理上是同一個操作。如果 AI 說兩者相等，而你的程式說不相等，就檢查看看是不是這個原因。這也是請 AI 解釋的好題目。

@section 常見疑問：布洛赫球的幾個陷阱
**問：|0⟩ 和 |1⟩ 在布洛赫球上是相反的兩極，但它們不是「相差 180 度」的向量嗎？**
這是最容易混淆的地方。在狀態向量的空間裡，|0⟩ 和 |1⟩ 是**互相垂直**（正交）的，夾角 90 度；但在布洛赫球上，它們被畫成**相反方向**，夾角 180 度。原因是布洛赫球的角度是狀態空間角度的**兩倍**。這也是為什麼 Ry(θ) 的矩陣裡出現的是 θ/2：在布洛赫球上轉 θ，對應到狀態向量只轉了 θ/2。

**問：整體相位真的完全不重要嗎？**
對**單一個**、孤立的量子系統來說，|ψ⟩ 和 −|ψ⟩ 的所有測量結果都完全相同，所以布洛赫球不畫出整體相位。但如果這個量子位元是某個更大系統的一部分，例如它是受控操作的控制位元，那原本的「整體相位」可能變成「相對相位」而影響結果。第 91 課的相位回踢，就是利用這個現象。

**問：X 閘和古典的 NOT 一樣嗎？**
作用在 |0⟩ 和 |1⟩ 上時一樣，但 X 閘作用在疊加態上時，會把兩個機率幅互換。例如 X 把 (0.6|0⟩ + 0.8|1⟩) 變成 (0.8|0⟩ + 0.6|1⟩)。在布洛赫球上，X 閘是繞 x 軸轉 180 度，所以 |+⟩（剛好在 x 軸上）經過 X 閘後完全不變。

**問：H 閘做兩次為什麼會回到原點？**
H 閘在布洛赫球上，是繞著 x 軸和 z 軸「中間」那條斜軸轉 180 度。任何轉 180 度的操作，做兩次就是轉 360 度，回到原處。數學上，H × H = I（單位矩陣）。這個性質在第 91 課的演算法中非常重要：「H → 某個操作 → H」的結構，常常能把相位資訊轉換成可測量的結果。

**問：為什麼硬體上通常只提供少數幾種閘？**
因為任意單量子位元操作，都可以拆成幾個旋轉閘的組合（例如 Rz、Ry、Rz 三個旋轉，這叫做歐拉角分解）。硬體只要把少數幾種閘做到非常精準，編譯器就會把你寫的電路自動轉換成這些閘。在 IBM 的超導硬體上，Rz 閘甚至是「虛擬」的，只要調整之後控制脈衝的相位，完全不花時間、也沒有錯誤。

@section 延伸練習：在布洛赫球上走一圈
**練習一：畫出旋轉軌跡**
用解答中的 bloch 函式，把 Ry(θ)|0⟩ 的 θ 從 0 走到 2π，每 15 度記錄一次座標。你會發現狀態在 x–z 平面上畫出一個大圓。再換成 Rx(θ)，觀察它畫出的是哪一個平面上的圓。

**練習二：找出「同一個點」的不同走法**
試著用不同的閘組合，把 |0⟩ 送到 |+i⟩（赤道上 y 方向的點）。例如「H 再 S」是一種走法，「Rx(−π/2)」是另一種。驗證兩者得到的狀態向量只差一個整體相位。這能讓你體會「同一個量子操作有很多種電路寫法」，也是量子編譯器在做的事情。

**練習三：在 Qiskit 中視覺化**
安裝 Qiskit 後，可以用 `Statevector` 搭配 `plot_bloch_multivector` 畫出布洛赫球。把本課範例中的每個狀態都畫一次，和程式算出的座標對照。如果畫出來的位置和你預期的不一樣，通常是把 θ 和 θ/2 搞混了。

**和量子機器學習的關係**
第 99 課的資料編碼，常常就是用 Ry(x) 把一個特徵值 x 變成布洛赫球上的一個點。不同的資料點落在球面的不同位置，量子分類器要做的事，就是找到一個旋轉，讓兩類資料分別靠近北極和南極。先在單一量子位元上建立這個幾何直覺，之後讀量子機器學習會輕鬆很多。

@section 動動腦：判斷看看
**題一**：布洛赫球赤道上的兩個不同的點，測量 0 和 1 的機率有什麼不同？
→ 沒有不同，都是各一半；它們的差別在於相對相位（經度），會影響後續的干涉。

**題二**：Z 閘作用在 |0⟩ 上，結果是什麼？作用在 |+⟩ 上呢？
→ |0⟩ 不變；|+⟩ 變成 |−⟩。Z 閘只翻轉 |1⟩ 那一項的正負號。

**題三**：要分辨 |+⟩ 和 |−⟩，應該怎麼做？
→ 先做 H 閘，|+⟩ 變成 |0⟩、|−⟩ 變成 |1⟩，再測量即可百分之百分辨。

**題四**：為什麼旋轉閘 RY(θ) 在量子機器學習中很重要？
→ 它的角度 θ 是可以連續調整的參數，能像神經網路的權重一樣被訓練。

**題五**：H 閘、X 閘、H 閘依序作用的效果等於哪個閘？
→ Z 閘。因為 H 閘把 X 軸和 Z 軸互換。

@section 本課重點整理
- **布洛赫球**：單一量子位元的所有狀態都是球面上的一點；北極 |0⟩、南極 |1⟩、赤道上是一半一半的疊加。
- **緯度決定測量機率，經度是相對相位**；整體相位不影響任何測量結果。
- **泡利閘 X、Y、Z**：繞三個軸轉 180 度；X 是位元翻轉，Z 是相位翻轉，也是最基本的錯誤類型。
- **H 閘**：製造疊加、互換 X 軸與 Z 軸；做兩次回到原狀，是干涉的最簡單例子。
- **S、T 閘與旋轉閘**：轉任意角度；T 閘在容錯量子計算中特別昂貴；旋轉閘的角度是量子機器學習的可訓練參數。
- **任何單量子位元閘都能用三次旋轉組合**。

@term 布洛赫球
把單一量子位元的所有狀態表示為球面上一點的幾何圖像（Bloch Sphere）。
@term 相對相位
疊加狀態中兩個機率幅之間的角度差，對應布洛赫球上的經度；不影響單次測量機率，但影響干涉。
@term 整體相位
所有機率幅同時乘上的相同相位，不影響任何測量結果，物理上可忽略（Global Phase）。
@term 泡利閘
X、Y、Z 三個基本量子閘，分別代表繞布洛赫球三個軸旋轉 180 度（Pauli Gates）。
@term 位元翻轉
把 |0⟩ 與 |1⟩ 互換的操作，對應 X 閘，也是一種基本錯誤類型（Bit Flip）。
@term 相位翻轉
把 |1⟩ 項正負號反轉的操作，對應 Z 閘，也是一種基本錯誤類型（Phase Flip）。
@term 阿達瑪閘
把 |0⟩ 變成 |+⟩、|1⟩ 變成 |−⟩ 的量子閘，用來製造疊加（Hadamard Gate，H 閘）。
@term 旋轉閘
繞布洛赫球某個軸旋轉任意角度的量子閘，如 RX(θ)、RY(θ)、RZ(θ)。
@term 魔術態
執行 T 閘等非 Clifford 操作所需的特殊量子資源，製備成本高（Magic State）。
