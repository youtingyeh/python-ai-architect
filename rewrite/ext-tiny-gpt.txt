@section 開場：把零件組裝成一台 GPT
前四課，我們收集了打造 GPT 所需的所有零件：
- **第 11 課**：自動微分引擎，讓模型能從錯誤中學習；
- **第 12 課**：語言模型的概念，以及用 NLL（交叉熵）打分數；
- **第 13 課**：分詞器，把文字切成 Token 編號；
- **第 14 課**：注意力機制，讓每個字能回頭看前文。

這一課，我們要像組裝一台機器一樣，把這些零件拼起來，變成一個完整的 **GPT**。

GPT 這三個字母各有意思：
- **G**enerative（生成式）：它會產生新的內容，而不只是分類或判斷。
- **P**re-trained（預訓練）：它先在大量文字上學會語言，之後才拿來做特定任務。
- **T**ransformer：它的架構就是上一課介紹的 Transformer。

Karpathy 寫了一個叫 **nanoGPT** 的專案，用大約 300 行程式就實作出和 GPT-2 相同的架構。他在課程中示範：用莎士比亞的全部作品（約 100 萬個字元）訓練一個小型 GPT，幾分鐘後，模型就能寫出看起來很像莎士比亞風格的劇本台詞。雖然內容常常沒有邏輯，但格式、用字、韻律都很像樣。

這一課我們會看懂：
1. 一台 GPT 從輸入到輸出，資料怎麼流動；
2. 每一層「Transformer 積木」裡面有什麼；
3. 為什麼能疊到 96 層還訓練得動；
4. 為什麼訓練很快、生成卻要一個字一個字慢慢來；
5. 為什麼「預訓練完的 GPT」還不是 ChatGPT。

@section GPT 的完整流程：資料從頭走到尾
想像資料是一條生產線上的原料，從入口走到出口。我們用張量的**形狀**來追蹤它（第 3 課學過，形狀是看懂深度學習程式最重要的線索）。

先定義幾個符號：
- **B**（Batch，批次）：一次同時處理幾段文字。例如 B = 32。
- **T**（Time，長度）：每段文字有幾個 Token。例如 T = 256。程式裡常叫 `block_size`，也就是模型的上下文視窗。
- **C**（Channels，通道數）：每個 Token 用多長的向量表示。例如 C = 768。也常寫成 `d_model`。
- **V**（Vocab，詞彙表大小）：例如 GPT-2 是 50,257。

**第一站：Token 編號。**
輸入是一批 Token 編號，形狀 (B, T)。每個數字代表一個 Token。

**第二站：兩種嵌入相加。**
- **字的嵌入**（wte，word token embedding）：查表，每個 Token 編號換成一組 C 維向量，代表「這個字的意思」。形狀變成 (B, T, C)。
- **位置的嵌入**（wpe，word position embedding）：查另一張表，每個位置 0、1、2……換成一組 C 維向量，代表「這是第幾個位置」。
- 兩者**相加**，每個 Token 的向量現在同時帶有「意思」和「位置」。

**第三站：穿過 N 層 Transformer 積木。**
這是模型的主體。GPT-2 小型版有 12 層，GPT-3 有 96 層。每一層的輸入和輸出形狀**都一樣**，都是 (B, T, C)。每穿過一層，每個 Token 的向量就更深入地融合了前文的資訊，從「這個字本身的意思」逐漸變成「這個字在這個上下文中的意思」。

**第四站：最後的正規化。**
經過一個 LayerNorm（等一下解釋），讓數值穩定。

**第五站：預測層（LM Head）。**
一個線性層把每個位置的 C 維向量，轉成 V 個分數（logits），形狀 (B, T, V)。第 t 個位置的 V 個分數，代表「下一個 Token 是詞彙表中每個 Token 的可能性」。經過 Softmax 就變成機率。

**規模感：**GPT-2 小型版約 1.24 億個參數；GPT-3 有 1,750 億個。但它們的結構**完全一樣**，差別只在 N（層數）和 C（向量長度）有多大。

@section Transformer 積木：先「開會」，再「各自思考」
每一層 Transformer 積木（Block）裡面，有兩個子模組輪流工作。Karpathy 給了一個非常好記的比喻：

**① 自注意力 = 開會（溝通）。**
上一課學的多頭因果自注意力。每個 Token 用 Query 去詢問前文，把相關的資訊收集到自己身上。這是 **Token 之間互相交流**的唯一時刻。

但注意力本質上只是一種「加權平均」：它把資訊收集過來，卻還沒對這些資訊做深入的加工。

**② 前饋網路（MLP）= 各自回座位思考（計算）。**
開完會後，每個 Token **各自獨立**消化剛剛收集到的資訊。在這個階段，Token 之間**完全不交流**，每個位置做一樣的運算，但各算各的。

MLP 的結構很固定：
1. 先把向量**放大 4 倍**：C 維 → 4C 維（例如 768 → 3072）。
2. 通過一個激活函式（GPT 用的是 **GELU**，可以想成一個更平滑的 ReLU，第 11 課提過 ReLU 會讓神經元死掉，GELU 改善了這點）。
3. 再**壓回** C 維。

「先放大、再壓回」讓模型有一個寬廣的空間去做複雜的非線性運算。

**MLP 有多重要？**它佔了 GPT 大約**三分之二的參數**。研究人員發現，MLP 很像一個巨大的「**知識倉庫**」：模型學到的事實（例如「巴黎是法國的首都」）很大一部分儲存在這裡。注意力負責「找到相關的上下文」，MLP 負責「根據上下文調出相關知識」。

**一層積木 = 開會 + 思考。**疊 12 層，就是開 12 次會、思考 12 輪。越往後的層，處理的概念越抽象：前面的層可能在處理文法和詞性，後面的層在處理語意、邏輯和事實。

@section 為什麼能疊這麼深？殘差連接與層正規化
把積木疊到 96 層，會遇到一個大麻煩：梯度要從最後一層傳回第一層，穿過幾百個矩陣乘法和激活函式。第 11 課學過，每經過一層梯度都可能打折，96 層下來可能就消失了（或者反過來，不斷放大到爆炸）。

GPT 用兩個關鍵技巧解決這個問題。

**技巧一：殘差連接（Residual Connection）。**

每個子模組不是直接取代輸入，而是把結果**加回**輸入上：

```
x = x + attention(x)
x = x + mlp(x)
```

這個簡單的「+ x」威力驚人。回憶第 11 課：**加法是梯度的影印機**，局部導數是 1，梯度原封不動地傳過去。所以在這條由一連串加法組成的「主幹道」上，梯度可以從最後一層**暢通無阻**地直接流回第一層。這被稱為「**梯度高速公路**」。

另一個角度看：每個子模組不需要學「完整的答案」，只需要學「在現有的基礎上**修改什麼**」。就像修改文件時，不用每次重寫整份，只要加上修訂就好。如果某一層覺得沒什麼好改的，它只要輸出接近 0，資料就幾乎原樣通過。這讓深層網路訓練起來容易得多。

殘差連接最早是 2015 年在圖片辨識模型 ResNet 中提出的，讓網路能從幾十層一口氣做到上百層，是深度學習史上最重要的發明之一。

**技巧二：層正規化（LayerNorm）。**

訓練過程中，向量裡的數字可能越變越大或越來越小，讓後面的層很難處理。**層正規化**會把每個 Token 的向量重新調整成「平均 0、標準差 1」，再讓模型學一組縮放和平移。就像考試成績標準化：不管這次考題難易，都換算成同一個標準來比較。

**擺放位置的小學問。**2017 年原始的 Transformer 把 LayerNorm 放在加法**之後**（叫 Post-LN）。GPT-2 之後的模型都改放在子模組**之前**（叫 Pre-LN）：

```
x = x + attention(layernorm(x))
x = x + mlp(layernorm(x))
```

這樣主幹道上的那條「x」完全不經過正規化，梯度高速公路保持暢通，大模型訓練初期穩定得多。

@section 訓練的巧思：一段文字同時出好幾道題
看 GPT 的訓練程式時，很多人會疑惑：輸入 x 的形狀是 (B, T)，答案 y 的形狀**也是** (B, T)。為什麼答案不是只有一個（下一個字）？

這是 GPT 訓練最聰明的設計：**一段文字，同時變成 T 道填空題。**

假設 T = 4，我們從語料中切出連續 5 個 Token：[15, 82, 43, 91, 27]。
- 輸入 x：前 4 個 → [15, 82, 43, 91]
- 答案 y：往右挪一格的後 4 個 → [82, 43, 91, 27]

這一段同時包含 4 道題目：
1. 只看 [15]，猜下一個 → 答案 82
2. 看 [15, 82]，猜下一個 → 答案 43
3. 看 [15, 82, 43]，猜下一個 → 答案 91
4. 看 [15, 82, 43, 91]，猜下一個 → 答案 27

**為什麼 4 道題可以在一次計算中同時做完，又不會互相作弊？**全靠上一課的**因果遮罩**：它保證第 t 個位置只能看到第 0 到 t 個 Token。所以第 1 題看不到 82 之後的東西，第 2 題看不到 43 之後的東西……各題完全獨立。

模型一次輸出 (B, T, V) 的分數，我們把它攤平成 (B×T, V)，答案攤平成 (B×T)，然後**一次**算交叉熵損失。一次前向、一次反向，就同時用上了 B × T 個訓練樣本。如果 B = 32、T = 256，一步就是 8,192 道題目！

這種效率，正是 Transformer 能用海量資料訓練的原因之一。另一個好處是：模型同時練習了「短上下文」和「長上下文」的預測，學得更全面。

@section 為什麼生成要一個字一個字來？
訓練時這麼平行、這麼快，為什麼你在 ChatGPT 打完問題後，答案卻要一個字一個字慢慢冒出來？

**因為未來還沒發生。**

訓練時，整篇文章早就存在硬碟裡，所有 Token 都已知，可以一次全部丟進去。但生成時，第 t+1 個字要**先生出來**，才能拿來預測第 t+2 個字。每一步都依賴上一步的結果，所以只能排隊。這就是第 12 課的**自回歸生成**。

nanoGPT 的生成迴圈，每產生一個新 Token 要做四件事：

1. **裁切**：如果目前的文字長度超過模型的上下文上限（block_size），只保留最後 block_size 個 Token。因為位置嵌入表只有 block_size 格，超過會查不到（程式會報索引越界錯誤）。這也是為什麼聊天太長時，模型會「忘記」最前面的內容。
2. **前向計算**：整段丟進模型，得到每個位置的分數。
3. **只取最後一個位置**：我們只關心「下一個字」，所以只取最後一個位置的 V 個分數，經過 Softmax 變成機率。
4. **抽樣並接上**：按機率抽一個 Token，接到文字尾端，回到第 1 步。

**加速技巧：KV Cache。**
注意到一個浪費：每生成一個字，都要把前面所有字重新算一次 Key 和 Value。但前面的字沒有變，它們的 K 和 V 也不會變！

所以實務上的推論系統（例如 vLLM）會把算過的 K 和 V **存起來**（快取，Cache）。每一步只需要算新 Token 的 Q、K、V，再跟快取中的舊 K、V 做注意力。這叫做「**KV Cache**」，能大幅加快生成速度，代價是佔用更多顯示卡記憶體。這也是長對話會讓推論變貴的原因之一。

**控制隨機程度：溫度（Temperature）。**
抽樣前，可以先把分數除以一個叫「溫度」的數字：
- 溫度 < 1（例如 0.2）：分數差距被放大，機率更集中在最高的選項，輸出更穩定、保守、可預測。適合寫程式、回答事實問題。
- 溫度 = 1：照原始機率抽樣。
- 溫度 > 1（例如 1.5）：分數差距被縮小，冷門選項更有機會被選中，輸出更有創意，但也更容易胡言亂語。

另外還有 **Top-k**（只從機率最高的 k 個 Token 中抽）和 **Top-p**（只從累積機率達到 p 的那些 Token 中抽），都是避免抽到太離譜選項的方法。

@section 看著模型長大：莎士比亞實驗
Karpathy 在課程中用莎士比亞全集訓練一個小 GPT（以字元為 Token，詞彙表只有 65 個符號）。最有趣的是觀察訓練過程中，模型寫出來的東西怎麼一步步變化：

**剛開始（還沒訓練）**：損失約 4.17，剛好等於 $\ln 65$，也就是在 65 個字元中完全瞎猜（第 12 課的公式）。生成的文字是一堆隨機符號，像 `pYCXxfRkRZd&W$Q!`。

**訓練一陣子**：模型先學會最表面的統計規律：空白和換行的頻率、母音子音的交替、常見的短字（the、and、to）。文字開始「長得像英文」，但沒有一個完整的句子。

**訓練更久**：模型學會了劇本的**格式**：角色名字大寫、後面加冒號、然後換行接台詞。它也學會了莎士比亞時代的用字風格，像 thou、thy、hath。

**最終（損失降到約 1.5）**：生成的內容像這樣的感覺——角色名、台詞、段落結構都對了，單字幾乎都是真的英文字，但句子的意思常常不知所云。

**這個過程告訴我們兩件事：**
1. 模型學習是**由淺入深**的：先學字母頻率，再學單字，再學格式，最後才是意思。和人類學語言的順序很像。
2. 「**格式像樣」不等於「真的懂」**。這個小模型只有約 1,000 萬個參數，資料也只有 100 萬字，足以學會格式，但遠遠不夠學會劇情邏輯。要讓內容有意義，需要大上千倍的模型和資料。這正是近年「規模定律」（Scaling Laws）的研究主題：模型、資料和計算量一起放大，能力就會穩定提升。

另外，Karpathy 也示範了訓練損失和驗證損失的差距：如果把模型做得太大、訓練太久，訓練損失繼續下降，但驗證損失開始上升，生成的內容開始**逐字背誦**原文片段。這就是第 9 課的過擬合，在語言模型上的樣子。他用 Dropout（訓練時隨機關掉一部分神經元）來緩解。

@section 預訓練完的 GPT，還不是 ChatGPT
假設我們用幾百億字的網路資料（維基百科、新聞、論壇、程式碼……）訓練好一個 GPT，任務只有一個：**預測下一個 Token**。得到的模型叫做「**基礎模型**」（Base Model）。

你問它：「請問台灣最高的山是哪一座？」

它可能會回答：「請問台灣最長的河流是哪一條？請問台灣人口最多的城市是哪裡？」

**為什麼？**因為在網路上，一連串問題接著出現（像一份考卷或常見問題清單）的情況，遠比「一問一答」常見。基礎模型只是在**模仿網路文件的樣子**，它不知道自己應該「回答問題」。它是一個「**文件接龍機**」，不是助理。

**從基礎模型到 ChatGPT，還要兩個階段：**

**① 監督式微調（SFT，Supervised Fine-Tuning）。**
請人類寫大量高品質的「問題 → 好的回答」範例（通常數萬到數十萬筆），讓模型繼續訓練。訓練方法和預訓練完全一樣，還是「預測下一個 Token」，只是資料換成了對話格式。模型因此學會：「看到使用者的問題，接下來應該寫一個有幫助的回答。」

這時第 13 課提到的**特殊 Token** 就派上用場了：用 `<|im_start|>user`、`<|im_start|>assistant` 這類標記，告訴模型「哪段是使用者說的、哪段是助理該說的」。

**② 人類回饋強化學習（RLHF，Reinforcement Learning from Human Feedback）。**
讓模型對同一個問題產生好幾個回答，請人類評分哪個比較好。用這些偏好資料訓練一個「**獎勵模型**」，學會判斷回答的好壞。再用它來引導 GPT，讓模型越來越傾向產生人類喜歡的回答：更有幫助、更誠實、更安全。

Karpathy 用一個比喻：預訓練像是讀遍圖書館的書，獲得廣博的知識；SFT 像是看大量的範例，學會怎麼當一個助理；RLHF 像是實際上工、根據顧客回饋不斷修正。

**重點是：知識幾乎都來自預訓練。**SFT 和 RLHF 用的資料量很小，主要是在教模型「**怎麼表現**」，而不是教它新知識。後面講微調的課程還會再談到這一點。

@section 動動腦：算算看 GPT-2 有多大
用 GPT-2 小型版的設定：V = 50,257、T = 1,024、C = 768、N = 12 層。

**① 字的嵌入表**：V × C = 50,257 × 768 ≈ **3,860 萬**。

**② 位置嵌入表**：T × C = 1,024 × 768 ≈ **79 萬**。

**③ 每一層積木：**
- 注意力：Q、K、V 三個矩陣加輸出矩陣，共 4 個 C × C ≈ 4 × 59 萬 ≈ **236 萬**。
- MLP：C × 4C 再 4C × C，共 8 × C² ≈ **472 萬**。
- 合計每層約 **708 萬**（忽略偏置和 LayerNorm 的少量參數）。
- 12 層 ≈ **8,500 萬**。

**④ 預測層**：GPT-2 讓它和字的嵌入表**共用同一組權重**（叫做權重綁定，Weight Tying），所以不另外計算。

**總計**：3,860 萬 + 79 萬 + 8,500 萬 ≈ **1.24 億**。和官方公布的數字吻合！

**觀察：**
- MLP 在每層佔了三分之二的參數（472 萬 vs 236 萬），和前面說的一致。
- 嵌入表佔了將近三分之一，這就是第 13 課說「詞彙表越大、模型越胖」的實際例子。
- 權重綁定省下了 3,860 萬個參數。直覺是：「把字變成向量」和「把向量變回字」本來就是互逆的動作，共用一張表很合理。

@section 本課重點整理
- **GPT** = 生成式、預訓練、Transformer。nanoGPT 用約 300 行程式實作出與 GPT-2 相同的架構。
- **資料流程**：Token 編號 → 字嵌入 + 位置嵌入 → N 層 Transformer 積木 → LayerNorm → 預測層 → 每個位置對下一個 Token 的分數。
- **每層積木**：自注意力（開會溝通）+ MLP（各自思考）。MLP 先放大 4 倍再壓回，佔約三分之二參數，像知識倉庫。
- **殘差連接**：`x = x + 子模組(x)`，加法讓梯度暢通，形成梯度高速公路，讓網路能疊很深。
- **層正規化**：把向量調整到穩定的範圍。現代模型放在子模組之前（Pre-LN）。
- **平行訓練**：一段長度 T 的文字同時提供 T 道題目，靠因果遮罩防止作弊。
- **逐字生成**：未來的字還不存在，只能一步一步產生。KV Cache 加速，溫度控制隨機程度。
- **基礎模型 ≠ 助理**：預訓練只學會文件接龍。還要經過 SFT（看範例學當助理）和 RLHF（根據人類偏好修正），才變成 ChatGPT。

@term GPT
生成式預訓練 Transformer（Generative Pre-trained Transformer），OpenAI 的語言模型系列，也泛指這類架構。
@term nanoGPT
Karpathy 的開源專案，用約 300 行程式實作與 GPT-2 相同的架構，適合學習。
@term block_size
模型一次能處理的最大 Token 數，也就是上下文視窗長度。
@term MLP
多層感知機（Multi-Layer Perceptron），在 Transformer 中是每個位置獨立運算的前饋網路。
@term GELU
一種比 ReLU 更平滑的激活函式，GPT 系列使用。
@term 層正規化
把每個向量調整成平均 0、標準差 1 的技巧（LayerNorm），讓訓練更穩定。
@term 梯度高速公路
殘差連接形成的加法主幹道，讓梯度能直接從輸出層流回輸入層。
@term KV Cache
生成時把已算過的 Key 和 Value 存起來，避免重複計算、加快生成速度的技巧。
@term 溫度
抽樣前用來調整機率分布尖銳程度的參數（Temperature）。低溫保守穩定，高溫多樣有創意。
@term Top-p
只從累積機率達到 p 的那些候選 Token 中抽樣的方法，避免抽到太離譜的選項。
@term 基礎模型
只經過預訓練、會做文件接龍但不會當助理的模型（Base Model）。
@term SFT
監督式微調（Supervised Fine-Tuning）：用人類寫的問答範例繼續訓練，讓模型學會當助理。
@term RLHF
人類回饋強化學習：依人類對回答的偏好訓練獎勵模型，再用它引導模型產生更好的回答。
@term 權重綁定
讓輸入嵌入表和輸出預測層共用同一組權重的技巧（Weight Tying），可省下大量參數。
