@section 開場：把量子電路當作神經網路
上一課看到，變分量子演算法和機器學習的訓練迴圈非常相似。**量子機器學習**（Quantum Machine Learning，QML）就是把這個想法推到底：**用參數化量子電路當作機器學習模型**，拿來做分類、迴歸、生成等任務。

本課與下一課參考三份公開教材的主題安排：
- IBM 的「**Quantum Machine Learning with Qiskit**」課程（參數化電路、資料編碼、變分分類、特徵映射與核方法、QGAN）；
- openHPI 的「**Quantum Machine Learning**」課程（IBM Quantum 研究員 Christa Zoufal、Julien Gacon、David Sutter 等主講）；
- GitHub 開源教材「**Learn Quantum Machine Learning**」（資料再上傳、QAOA、傅立葉級數觀點、有雜訊的電路）。

這一課是 QML 的上半部，重點放在**監督式學習**：
- 古典資料怎麼放進量子電路（**資料編碼**）；
- 變分量子分類器的結構與訓練；
- **資料再上傳**：讓單一量子位元也能做非線性分類；
- 量子模型其實是**傅立葉級數**：一個理解 QML 能力上限的重要觀點；
- 梯度計算的實務。

下一課再談核方法、生成模型，以及 QML 面臨的重大挑戰（貧瘠高原、去量子化）。

@section 資料編碼：把古典資料放進量子態
**為什麼這是第一個難題**
機器學習的資料通常是古典的數字向量，例如一張圖片的像素、一位病人的檢驗數值。量子電路只能處理量子態，所以第一步一定是**編碼**（encoding），也叫**特徵映射**（feature map）。第 92 課提過的**資料載入瓶頸**，在這裡會直接影響模型的效率和能力。

**一、基底編碼（Basis Encoding）**
把資料轉成二進位，直接對應到計算基底。例如 5 = 101，就準備 |101⟩。簡單，但只適合離散資料，而且每個位元需要一個量子位元。

**二、角度編碼（Angle Encoding）**
最常用的方法。每個特徵 xᵢ 變成一個旋轉角度，例如對第 i 個量子位元做 Ry(xᵢ)。
- 優點：電路非常淺（只有一層旋轉）；
- 缺點：n 個特徵需要 n 個量子位元；
- 注意：角度是週期性的（轉 2π 等於沒轉），所以資料通常要先**縮放**到 [0, π] 之類的範圍，這和深度學習中的特徵標準化很像。

**三、振幅編碼（Amplitude Encoding）**
把 N 個特徵（正規化後）直接當作量子態的 N 個機率幅。只需要 log₂N 個量子位元，例如 1024 個特徵只要 10 個量子位元！
- 優點：量子位元極省，是許多「指數加速」宣稱的基礎；
- 缺點：準備任意振幅編碼的狀態，一般需要約 N 個閘，深度很大。這個成本常常把理論上的加速抵消掉。

**四、IQP 型或高階特徵映射**
在角度編碼之後，再加上糾纏閘，並把**特徵的乘積**（例如 x₁ × x₂）也編碼成相位。IBM 2019 年在 Nature 發表的量子核方法論文（Havlíček 等人）就用了這類映射，設計目標是讓這種映射**難以用古典電腦模擬**。

**編碼方式決定了模型能學什麼**
這是 QML 最重要的觀念之一：**編碼不只是前處理，它決定了模型的函數空間**。後面講傅立葉觀點時會看得更清楚。

@section 變分量子分類器
**結構**
一個典型的**變分量子分類器**（Variational Quantum Classifier，VQC）由三部分組成：
1. **編碼層** S(x)：把資料 x 放進量子態；
2. **變分層** W(θ)：帶有可訓練參數的電路，通常是「旋轉 + 糾纏」重複幾層；
3. **測量**：測量某個可觀測量（例如第一個量子位元的 Z），得到期望值 ⟨Z⟩，範圍在 −1 到 +1 之間。

模型的輸出是：
f(x; θ) = ⟨0| S(x)† W(θ)† Z W(θ) S(x) |0⟩

看起來很複雜，意思其實很簡單：「編碼 → 變換 → 測量期望值」。

**怎麼變成分類結果？**
- 二元分類：⟨Z⟩ > 0 判為類別 A，否則判為類別 B；
- 也可以把 (1 + ⟨Z⟩)/2 當作機率，配合交叉熵損失訓練；
- 多類別：測量多個量子位元，或把測量結果的不同位元字串對應到不同類別。

**訓練迴圈**
和第 8 課的 PyTorch 訓練迴圈幾乎一樣：
1. 取一批訓練資料；
2. 對每筆資料執行電路、估計 ⟨Z⟩（需要很多 shot）；
3. 計算損失（例如均方誤差或交叉熵）；
4. 用參數平移規則計算梯度；
5. 更新參數；
6. 重複。

**和古典神經網路的差異**
- **輸出天生有界**：期望值在 −1 到 +1 之間；
- **沒有傳統意義的非線性激活函數**：量子電路對量子態的作用是**線性**的（么正矩陣）。非線性來自**資料編碼**（例如 cos 和 sin）和**測量**（機率是機率幅的平方）；
- **每次前向傳播都有統計雜訊**：期望值是用有限 shot 估計的；
- **參數效率**：一些研究顯示，量子模型用很少的參數就能表達某些函數，但這不代表它在實際資料上比較好。

**工具**
主流的 QML 框架有：Qiskit Machine Learning（IBM）、**PennyLane**（Xanadu，可以和 PyTorch、JAX 整合）、TensorFlow Quantum（Google）。PennyLane 尤其受歡迎，因為它能把量子電路當成 PyTorch 的一層，和古典神經網路混合使用。

@section 資料再上傳：單一量子位元的分類器
**一個令人驚訝的結果**
2020 年，Pérez-Salinas 等人發表論文「Data re-uploading for a universal quantum classifier」，提出一個簡單但強大的想法：**把資料重複編碼很多次**，中間穿插可訓練的層：
S(x) → W(θ₁) → S(x) → W(θ₂) → S(x) → W(θ₃) → 測量

他們證明：即使只用**一個量子位元**，只要重複足夠多次，就能逼近任意的分類邊界，例如把平面上的點依照「在圓內或圓外」分類，這是一個非線性問題。

**為什麼有效？**
- 只編碼一次時，模型能表達的函數很有限；
- 每重複一次，資料和參數就交織得更複雜，模型的表達能力就增加；
- 這很像古典神經網路中「增加層數」的效果。

**和古典神經網路的類比**
論文作者把它比喻成：單一量子位元就像一個神經元，資料再上傳就像讓這個神經元「多看幾次」輸入。重複的次數，類似於神經網路的深度。

**實務意義**
資料再上傳是 Learn-QML 等教材的核心主題之一，它告訴我們：**量子模型的能力，很大程度取決於資料被編碼幾次、以什麼方式編碼**，而不只是量子位元數量。

@section 傅立葉觀點：量子模型能學什麼函數？
**一個漂亮的理論結果**
2021 年，Schuld、Sweke 與 Meyer 發表論文「Effect of data encoding on the expressive power of variational quantum machine learning models」，證明了一件事：

**當資料用旋轉閘（例如 Rx(x)、Ry(x)）編碼時，量子模型的輸出 f(x) 一定可以寫成一個截斷的傅立葉級數：**
f(x) = Σ c_ω × e^(iωx)

也就是一堆不同頻率的正弦和餘弦波的加權總和。

**誰決定了什麼？**
- **頻率 ω 有哪些**：由**資料編碼**決定。每用旋轉閘編碼一次，可用的頻率範圍就擴大一些。只編碼一次，模型只能表達頻率 0 和 1 的函數，基本上就是一個正弦波加常數；編碼 L 次，頻率可以到 L；
- **係數 c_ω 是多少**：由**可訓練的變分層**決定。

**這個觀點的重要意義**
1. **解釋了資料再上傳為什麼有效**：重複編碼增加了可用的頻率，模型就能擬合更複雜的函數；
2. **給了量子模型能力的上限**：如果你的編碼只能產生少數頻率，不管變分層多大、參數多少，模型都學不會高頻的細節；
3. **提供了和古典模型比較的方法**：既然量子模型是傅立葉級數，那麼一個古典的傅立葉模型（或用隨機傅立葉特徵的方法）是否也能做到一樣好？下一課的「**去量子化**」就從這個問題出發。

**生活比喻**
想像你只能用幾種固定的音高（頻率）來合成一段音樂。編碼決定了「鋼琴上有哪些琴鍵」，訓練決定了「每個琴鍵按多大聲」。琴鍵太少，再怎麼調整力道，也彈不出複雜的旋律。

@section 梯度計算與訓練實務
**參數平移規則（複習與延伸）**
上一課介紹過：對於 e^(−iθP/2) 形式的旋轉閘（P 是泡利矩陣），梯度可以精確地用兩次電路執行計算：
∂f/∂θ = [f(θ + π/2) − f(θ − π/2)] / 2

**成本問題**
m 個參數、每次估計用 S 個 shot、訓練資料 B 筆，一次梯度更新需要大約 2 × m × B × S 次電路執行。假設 m = 100、B = 32、S = 1000，就是 640 萬次執行。在雲端量子硬體上，這是非常昂貴的。這也是為什麼許多 QML 研究只能在模擬器上做，或只用很小的模型。

**和反向傳播的對比**
古典神經網路的反向傳播，計算所有參數的梯度，成本只是前向傳播的幾倍，**和參數數量幾乎無關**。量子電路因為不能「偷看中間狀態」，目前沒有同樣有效率的方法。這是量子模型在**訓練效率**上的根本劣勢。2023 年以後，有研究探討量子電路是否能有類似反向傳播的擴展性，結論是一般情況下很困難。

**模擬器上的技巧**
在一般電腦上模擬量子電路時，可以直接取得完整的狀態向量，所以能用**自動微分**（像 PyTorch 那樣）或 **adjoint 方法**快速算梯度。這只適用於模擬，不適用於真實硬體。

**實用建議**
- **先在無雜訊模擬器上確認模型能學**，再加雜訊，最後才上真實硬體；
- **從很小的模型開始**：少量量子位元、少量層；
- **一定要和古典基準比較**：例如邏輯斯迴歸、小型神經網路、SVM。如果量子模型連簡單的古典模型都打不過，就不該宣稱優勢；
- **報告完整設定**：量子位元數、層數、shot 數、優化器、雜訊模型、資料集。

@section 和 AI 一起做：讓 AI 幫你做公平的比較實驗
QML 是一個很容易「被 AI 的熱情帶著走」的主題：問 AI「量子機器學習有什麼優勢」，它可能會列出一長串聽起來很美好的優點。比較好的協作方式，是請 AI 幫你**設計公平的實驗**。

**請 AI 實作資料再上傳分類器，並加上古典對照組**
```
請用純 NumPy 實作單量子位元的資料再上傳分類器：
- 資料：平面上隨機 200 個點，標籤為「是否在半徑 0.7 的圓內」
- 每層：用 Rz(x₁)·Ry(x₂) 編碼，接 Ry(θ)·Rz(φ) 可訓練旋轉
- 輸出 ⟨Z⟩，損失用均方誤差，梯度用參數平移規則
- 比較 1、2、4、8 層的測試準確率
- 同時訓練一個古典對照組：sklearn 的 MLPClassifier（隱藏層 8 個神經元）
- 印出兩者的準確率和參數數量
```
這個實驗會讓你看到兩件事：資料再上傳的層數確實影響表達能力；而在這個簡單問題上，古典小網路也能做得很好。

**請 AI 驗證傅立葉觀點**
請 AI 寫一個實驗：單一量子位元，用 Rx(x) 編碼 L 次，中間穿插隨機的固定旋轉，畫出 f(x) 並計算它的離散傅立葉轉換，驗證最高頻率確實等於 L。這是用程式「親手證明」理論的好例子。

**請 AI 列出報告檢查清單**
讀到 QML 論文或新聞時，請 AI 幫你檢查：
- 有沒有和適當的古典模型比較？
- 資料集是不是太小、太簡單？
- 是在模擬器還是真實硬體上？
- 編碼方式的成本有沒有算進去？

@section 動動腦：判斷看看
**題一**：用振幅編碼存放 1024 個特徵，需要幾個量子位元？主要的代價是什麼？
→ 10 個（log₂1024）。代價是準備任意振幅狀態一般需要約 N 個閘，電路很深。

**題二**：量子電路對量子態的作用是線性的，那量子分類器的非線性從哪裡來？
→ 來自資料編碼（旋轉角度產生 cos、sin）和測量（機率是機率幅的平方）。

**題三**：一個量子模型只用 Ry(x) 編碼資料一次，它能學會高頻率振盪的函數嗎？
→ 不能。依照傅立葉觀點，只編碼一次的模型只能表達頻率 0 和 1 的成分；需要多次編碼（資料再上傳）才能增加頻率。

**題四**：資料再上傳的核心想法是什麼？
→ 把資料重複編碼多次，中間穿插可訓練層，以增加模型表達能力；單一量子位元也能做非線性分類。

**題五**：為什麼量子模型的訓練成本比古典神經網路高很多？
→ 參數平移規則每個參數都要兩次電路執行，每次還要很多 shot；古典反向傳播的成本則和參數數量幾乎無關。

@section 本課重點整理
- **QML**：用參數化量子電路當作機器學習模型；本課與下一課參考 IBM、openHPI 與 Learn-QML 的教材主題。
- **資料編碼**：基底、角度、振幅、IQP 型；編碼決定模型的函數空間，振幅編碼省量子位元但準備成本高。
- **變分量子分類器**：編碼 → 變分層 → 測量期望值；訓練迴圈和古典深度學習類似。
- **非線性來源**：編碼與測量，而不是么正演化本身。
- **資料再上傳**：重複編碼增加表達能力，單一量子位元即可逼近任意分類邊界。
- **傅立葉觀點**：旋轉編碼的量子模型是截斷傅立葉級數；編碼決定頻率，訓練決定係數。
- **梯度成本**：參數平移規則需要 2m 次執行乘以資料與 shot 數；缺乏有效的量子反向傳播。
- **實務**：先模擬後硬體、從小模型開始、一定要和古典基準比較。

@term 量子機器學習
以量子電路作為機器學習模型或加速器的研究領域（Quantum Machine Learning, QML）。
@term 資料編碼
把古典資料轉換成量子態的步驟，又稱特徵映射（Data Encoding / Feature Map）。
@term 角度編碼
把每個特徵當作旋轉閘角度的編碼方式（Angle Encoding）。
@term 振幅編碼
把正規化後的資料向量直接當作量子態機率幅的編碼方式（Amplitude Encoding）。
@term 變分量子分類器
由編碼層、可訓練變分層與測量組成的量子分類模型（Variational Quantum Classifier, VQC）。
@term 資料再上傳
在電路中多次重複編碼資料並穿插可訓練層以提高表達能力的技巧（Data Re-uploading）。
@term 傅立葉級數觀點
旋轉閘編碼的量子模型輸出可寫成截斷傅立葉級數，頻率由編碼決定、係數由訓練決定。
@term PennyLane
Xanadu 開發的開源量子機器學習框架，可與 PyTorch、JAX 整合。
